    1. Selection Sort

    Difficulty: LOW

    Statement/Hint: Sort an array using Selection Sort.

    Example: - Input: nums = [64, 25, 12, 22, 11] - Output: [11, 12, 22, 25, 64]

    Approach: Selection Sort - For each position i from 0 to n-1, find the index of the minimum element in the unsorted suffix (i..n-1). - Swap that minimum into position i, growing the sorted prefix by one each pass. - Runs in O(n^2) time regardless of input order - no early exit on nearly-sorted input. - Makes at most n swaps total (one per pass), unlike bubble sort which can do many more - useful when write cost is expensive.

    Time / Space: O(n^2) time, O(1) space.

    public void selectionSort(int[] nums) {
    int n = nums.length;
    for (int i = 0; i < n - 1; i++) {
        int minIdx = i;
        for (int j = i + 1; j < n; j++) {
            if (nums[j] < nums[minIdx]) minIdx = j;
        }
        int tmp = nums[i]; nums[i] = nums[minIdx]; nums[minIdx] = tmp;
    }
}

    2. Bubble Sort

    Difficulty: LOW

    Statement/Hint: Sort an array using Bubble Sort.

    Example: - Input: nums = [5, 1, 4, 2, 8] - Output: [1, 2, 4, 5, 8]

    Approach: Bubble Sort (early exit) - Repeatedly sweep through the array, swapping adjacent elements that are out of order, so the largest unsorted element "bubbles up" to its correct position each pass. - After pass i, the last i elements are guaranteed sorted, so each subsequent pass can scan one fewer element. - Track whether any swap happened in a pass; if none did, the array is already sorted and you can exit early - this makes best-case O(n) on an already-sorted array. - Worst and average case is still O(n^2), with O(1) extra space, and it is stable (equal elements keep relative order).

    Time / Space: O(n^2) worst / O(n) best time, O(1) space.

    public void bubbleSort(int[] nums) {
    int n = nums.length;
    for (int i = 0; i < n - 1; i++) {
        boolean swapped = false;
        for (int j = 0; j < n - 1 - i; j++) {
            if (nums[j] > nums[j + 1]) {
                int tmp = nums[j]; nums[j] = nums[j + 1]; nums[j + 1] = tmp;
                swapped = true;
            }
        }
        if (!swapped) break;
    }
}

    3. Insertion Sort

    Difficulty: LOW

    Statement/Hint: Sort an array using Insertion Sort.

    Example: - Input: nums = [12, 11, 13, 5, 6] - Output: [5, 6, 11, 12, 13]

    Approach: Insertion Sort - Grow a sorted prefix one element at a time: take the next unsorted element and shift larger elements in the sorted prefix one step right to make room. - Insert the picked element into its correct position within the now-shifted prefix. - Best case (already sorted) is O(n) since the inner shifting loop never runs; worst case (reverse sorted) is O(n^2). - Stable and in-place (O(1) extra space); efficient for small or nearly-sorted arrays, which is why it is used as the base case in hybrid sorts like Timsort.

    Time / Space: O(n^2) worst / O(n) best time, O(1) space.

    public void insertionSort(int[] nums) {
    int n = nums.length;
    for (int i = 1; i < n; i++) {
        int key = nums[i];
        int j = i - 1;
        while (j >= 0 && nums[j] > key) {
            nums[j + 1] = nums[j];
            j--;
        }
        nums[j + 1] = key;
    }
}

    4. Merge Sort

    Difficulty: MEDIUM

    Statement/Hint: Sort an array using Merge Sort.

    Example: - Input: nums = [38, 27, 43, 3, 9, 82, 10] - Output: [3, 9, 10, 27, 38, 43, 82]

    Approach: Merge Sort - Divide and conquer: recursively split the array in half until each piece has one element (trivially sorted). - Merge two sorted halves by repeatedly comparing their fronts and copying the smaller one into a temporary buffer, then copy the buffer back. - Guarantees O(n log n) in all cases (best, average, worst) since the split is always balanced - no dependence on input order. - Needs O(n) extra space for the merge buffer, and is stable - makes it the go-to when guaranteed O(n log n) and stability both matter (e.g. external sorting, sorting linked lists).

    Time / Space: O(n log n) time, O(n) space.

    void merge(int[] nums, int lo, int mid, int hi) {
    int[] tmp = new int[hi - lo + 1];
    int i = lo, j = mid + 1, k = 0;
    while (i <= mid && j <= hi) {
        if (nums[i] <= nums[j]) tmp[k++] = nums[i++];
        else tmp[k++] = nums[j++];
    }
    while (i <= mid) tmp[k++] = nums[i++];
    while (j <= hi) tmp[k++] = nums[j++];
    System.arraycopy(tmp, 0, nums, lo, tmp.length);
}

public void mergeSort(int[] nums, int lo, int hi) {
    if (lo >= hi) return;
    int mid = (lo + hi) / 2;
    mergeSort(nums, lo, mid);
    mergeSort(nums, mid + 1, hi);
    merge(nums, lo, mid, hi);
}

    5. Recursive Bubble Sort

    Difficulty: LOW

    Statement/Hint: Sort an array using a recursive formulation of Bubble Sort.

    Example: - Input: nums = [5, 1, 4, 2, 8], n = 5 - Output: [1, 2, 4, 5, 8]

    Approach: Recursive Bubble Sort - Base case: an array of size 1 (or 0) is already sorted. - Do one bubble pass over the first n elements, which bubbles the largest element to the last position (index n-1). - Recurse on the remaining n-1 elements (excluding the now-fixed last element). - Same O(n^2) time complexity as iterative bubble sort, but trades the outer loop for O(n) recursion depth and stack space - mainly asked to test comfort translating iterative loops into recursion.

    Time / Space: O(n^2) time, O(n) recursion stack space.

    public void recursiveBubbleSort(int[] nums, int n) {
    if (n <= 1) return;
    for (int j = 0; j < n - 1; j++) {
        if (nums[j] > nums[j + 1]) {
            int tmp = nums[j]; nums[j] = nums[j + 1]; nums[j + 1] = tmp;
        }
    }
    recursiveBubbleSort(nums, n - 1);
}

    6. Recursive Insertion Sort

    Difficulty: LOW

    Statement/Hint: Sort an array using a recursive formulation of Insertion Sort.

    Example: - Input: nums = [12, 11, 13, 5, 6], n = 5 - Output: [5, 6, 11, 12, 13]

    Approach: Recursive Insertion Sort - Base case: an array of size 1 (or 0) is already sorted. - Recursively sort the first n-1 elements first, so by the time you handle index n-1 everything before it is already sorted. - Then insert nums[n-1] into its correct position within that sorted prefix, shifting larger elements right one at a time. - Same O(n^2) time as iterative insertion sort; the recursion replaces the outer "grow the sorted prefix" loop with callstack depth O(n).

    Time / Space: O(n^2) time, O(n) recursion stack space.

    public void recursiveInsertionSort(int[] nums, int n) {
    if (n <= 1) return;
    recursiveInsertionSort(nums, n - 1);
    int last = nums[n - 1];
    int j = n - 2;
    while (j >= 0 && nums[j] > last) {
        nums[j + 1] = nums[j];
        j--;
    }
    nums[j + 1] = last;
}

    7. Quick Sort

    Difficulty: HIGH

    Statement/Hint: Sort an array using Quick Sort.

    Example: - Input: nums = [10, 7, 8, 9, 1, 5] - Output: [1, 5, 7, 8, 9, 10]

    Approach: Quick Sort (Lomuto partition) - Pick a pivot (commonly the last element), then partition the array so everything smaller than the pivot ends up to its left and everything larger to its right - the pivot lands in its final sorted position. - Recurse independently on the left and right partitions around the pivot. - Average case O(n log n) with O(1) extra space (in-place partitioning), but worst case degrades to O(n^2) on already-sorted input with a naive pivot choice (e.g. always the first/last element) - randomized or median-of-three pivot selection avoids this. - Not stable (partitioning can reorder equal elements), unlike merge sort - a common interview follow-up contrasting the two.

    Time / Space: O(n log n) avg / O(n^2) worst time, O(log n) space.

    int partition(int[] nums, int lo, int hi) {
    int pivot = nums[hi];
    int i = lo - 1;
    for (int j = lo; j < hi; j++) {
        if (nums[j] < pivot) {
            i++;
            int tmp = nums[i]; nums[i] = nums[j]; nums[j] = tmp;
        }
    }
    int tmp = nums[i + 1]; nums[i + 1] = nums[hi]; nums[hi] = tmp;
    return i + 1;
}

public void quickSort(int[] nums, int lo, int hi) {
    if (lo >= hi) return;
    int p = partition(nums, lo, hi);
    quickSort(nums, lo, p - 1);
    quickSort(nums, p + 1, hi);
}
