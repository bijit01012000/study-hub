    1. Reverse Linked List

    Difficulty: HIGH

    Statement/Hint: Reverse a singly linked list in place (so the last node becomes the head).

    Example: - Input: head = 1→2→3→4→5 - Output: 5→4→3→2→1

    Approach: Iterative Three-Pointer - Iterative: walk the list with three pointers - prev (starts null), curr (starts at head), and a temporary next. At each step, save curr->next, point curr->next to prev, then advance prev and curr forward. When curr becomes null, prev is the new head. - Recursive: recurse to the end of the list first, then on the way back, set node->next->next = node and node->next = null; the base case (single node or null) returns the new head untouched. - The recursive version is O(n) space due to the call stack, versus O(1) for the iterative version - prefer iterative unless recursion is specifically requested. - O(n) time either way.

    Time / Space: O(n) time, O(1) space.

    public ListNode reverseList(ListNode head) {
    ListNode prev = null;
    ListNode curr = head;
    while (curr != null) {
        ListNode next = curr.next;
        curr.next = prev;
        prev = curr;
        curr = next;
    }
    return prev;
}

    2. Middle of the Linked List

    Difficulty: HIGH

    Statement/Hint: Find the middle node of a singly linked list in one pass (for even length, return the second of the two middle nodes).

    Example: - Input: head = 1→2→3→4→5 - Output: 3

    Approach: Slow/Fast Pointer - Use two pointers starting at head: slow moves one step at a time, fast moves two steps at a time. - When fast reaches the end (fast == null or fast->next == null), slow is at the middle. - Avoids the naive two-pass approach (count length, then walk length/2 steps) - this does it in a single pass. - O(n) time, O(1) space. This slow/fast pattern is the foundation for cycle detection and other two-pointer linked-list tricks.

    Time / Space: O(n) time, O(1) space.

    public ListNode middleNode(ListNode head) {
    ListNode slow = head, fast = head;
    while (fast != null && fast.next != null) {
        slow = slow.next;
        fast = fast.next.next;
    }
    return slow;
}

    3. Linked List Cycle

    Difficulty: HIGH

    Statement/Hint: Determine whether a singly linked list contains a cycle.

    Example: - Input: head = 3→2→0→-4, tail connects back to node with value 2 - Output: true

    Approach: Floyd's Cycle Detection - Floyd's Cycle Detection (tortoise and hare): use slow (1 step) and fast (2 steps) pointers starting at head. - If there's no cycle, fast (or fast->next) reaches null and you return false. - If there is a cycle, fast will eventually lap slow and they meet at the same node - return true when slow == fast. - O(n) time, O(1) space - beats the hash-set approach (storing visited node addresses) which is O(n) space, though that's a valid fallback if the pattern isn't recalled.

    Time / Space: O(n) time, O(1) space.

    public boolean hasCycle(ListNode head) {
    ListNode slow = head, fast = head;
    while (fast != null && fast.next != null) {
        slow = slow.next;
        fast = fast.next.next;
        if (slow == fast) return true;
    }
    return false;
}

    4. Linked List Cycle II (Cycle Start)

    Difficulty: MEDIUM

    Statement/Hint: Given a linked list that contains a cycle, find the node where the cycle begins.

    Example: - Input: head = 3→2→0→-4, tail connects back to node with value 2 - Output: node with value 2

    Approach: Floyd's Algorithm + Reset Pointer - First detect the cycle using Floyd's algorithm (slow/fast pointers) until they meet inside the loop. - Then reset one pointer to head, keep the other at the meeting point, and advance both one step at a time - they meet exactly at the cycle's starting node. - Why this works: if the distance from head to cycle start is L, and the meeting point is D steps into the cycle, the math of Floyd's algorithm guarantees the remaining distance from the meeting point back around to the cycle start equals L (mod cycle length) - so moving both pointers one step at a time synchronizes them at the start. - O(n) time, O(1) space.

    Time / Space: O(n) time, O(1) space.

    public ListNode detectCycle(ListNode head) {
    ListNode slow = head, fast = head;
    while (fast != null && fast.next != null) {
        slow = slow.next;
        fast = fast.next.next;
        if (slow == fast) {
            ListNode ptr = head;
            while (ptr != slow) {
                ptr = ptr.next;
                slow = slow.next;
            }
            return ptr;
        }
    }
    return null;
}

    5. Merge Two Sorted Lists

    Difficulty: HIGH

    Statement/Hint: Merge two sorted singly linked lists into one sorted linked list by splicing existing nodes (no new node values).

    Example: - Input: l1 = 1→2→4, l2 = 1→3→4 - Output: 1→1→2→3→4→4

    Approach: Dummy Head Splicing - Use a dummy head node to simplify edge cases (avoids special-casing which list's head becomes the result's head). - Maintain a tail pointer starting at dummy; at each step, compare the current nodes of both lists and attach the smaller one to tail->next, then advance that list's pointer and tail. - Once one list is exhausted, attach the remainder of the other list directly (it's already sorted). - O(n + m) time where n, m are the list lengths, O(1) extra space (just rewiring pointers, dummy node aside).

    Time / Space: O(n + m) time, O(1) space.

    public ListNode mergeTwoLists(ListNode l1, ListNode l2) {
    ListNode dummy = new ListNode(0);
    ListNode tail = dummy;
    while (l1 != null && l2 != null) {
        if (l1.val <= l2.val) {
            tail.next = l1;
            l1 = l1.next;
        } else {
            tail.next = l2;
            l2 = l2.next;
        }
        tail = tail.next;
    }
    tail.next = (l1 != null) ? l1 : l2;
    return dummy.next;
}

    6. Remove Nth Node From End of List

    Difficulty: MEDIUM

    Statement/Hint: Remove the nth node from the end of a singly linked list in a single pass.

    Example: - Input: head = 1→2→3→4→5, n = 2 - Output: 1→2→3→5

    Approach: Two-Pointer with Dummy Node - Use two pointers, both starting at a dummy node placed before head (handles the edge case of removing the head itself). - Advance a "fast" pointer n + 1 steps ahead of "slow" first, then move both one step at a time until fast reaches null - slow now sits just before the node to remove. - Unlink the target node via slow->next = slow->next->next. - The dummy node and the n + 1 (rather than n) head start are both there specifically to make head-removal and off-by-one boundaries fall out naturally instead of needing special-casing. - O(n) time (one pass), O(1) space.

    Time / Space: O(n) time, O(1) space.

    public ListNode removeNthFromEnd(ListNode head, int n) {
    ListNode dummy = new ListNode(0);
    dummy.next = head;
    ListNode slow = dummy, fast = dummy;
    for (int i = 0; i < n + 1; i++) fast = fast.next;
    while (fast != null) {
        slow = slow.next;
        fast = fast.next;
    }
    slow.next = slow.next.next;
    return dummy.next;
}

    7. Palindrome Linked List

    Difficulty: MEDIUM

    Statement/Hint: Determine whether a singly linked list reads the same forwards and backwards.

    Example: - Input: head = 1→2→2→1 - Output: true

    Approach: Find Middle + Reverse Second Half - Find the middle of the list using slow/fast pointers, then reverse the second half in place. - Compare the first half and the reversed second half node-by-node; if all values match, it's a palindrome. - Optionally reverse the second half back afterward to restore the original list structure (good practice if the list shouldn't be mutated for callers). - O(n) time, O(1) extra space - this beats the simpler approach of copying values into an array and checking with two pointers, which is O(n) space.

    Time / Space: O(n) time, O(1) space.

    public boolean isPalindrome(ListNode head) {
    ListNode slow = head, fast = head;
    while (fast != null && fast.next != null) {
        slow = slow.next;
        fast = fast.next.next;
    }
    ListNode prev = null;
    while (slow != null) {
        ListNode next = slow.next;
        slow.next = prev;
        prev = slow;
        slow = next;
    }
    ListNode left = head, right = prev;
    while (right != null) {
        if (left.val != right.val) return false;
        left = left.next;
        right = right.next;
    }
    return true;
}

    8. Delete Head of a Doubly Linked List

    Difficulty: LOW

    Statement/Hint: Delete the head node of a doubly linked list and return the new head.

    Example: - Input: head = 1⇄2⇄3⇄4 - Output: 2⇄3⇄4

    Approach: Direct Pointer Reassignment - The new head is head->next; if it exists, its prev pointer must be set to null (it no longer has a predecessor). - Handle the edge cases of an empty list (return null) and a single-node list (new head is null after deletion). - O(1) time, O(1) space.

    Time / Space: O(1) time, O(1) space.

    public DLLNode deleteHead(DLLNode head) {
    if (head == null) return null;
    DLLNode newHead = head.next;
    if (newHead != null) newHead.prev = null;
    return newHead;
}

    9. Reverse a Doubly Linked List

    Difficulty: LOW

    Statement/Hint: Reverse a doubly linked list in place.

    Example: - Input: head = 1⇄2⇄3⇄4⇄5 - Output: 5⇄4⇄3⇄2⇄1

    Approach: In-Place Pointer Swap - Walk the list one node at a time; at each node, swap its next and prev pointers (what was "forward" becomes "backward" and vice versa). - Save the original next pointer before swapping (since it's about to be overwritten) so traversal can continue to what was the next node. - The new head is the last node processed (the original tail) - track it as you go, or just return the final prev pointer since it ends up pointing at the last-swapped node. - O(n) time, O(1) space.

    Time / Space: O(n) time, O(1) space.

    public DLLNode reverseDLL(DLLNode head) {
    if (head == null || head.next == null) return head;
    DLLNode temp = head, prev = null;
    while (temp != null) {
        DLLNode nextNode = temp.next;
        temp.next = prev;
        temp.prev = nextNode;
        prev = temp;
        temp = nextNode;
    }
    return prev;
}

    10. Reverse Linked List (Recursive)

    Difficulty: MEDIUM

    Statement/Hint: Reverse a singly linked list using recursion (rather than the iterative three-pointer approach).

    Example: - Input: head = 1→2→3→4→5 - Output: 5→4→3→2→1

    Approach: Recursive Reversal - Recurse to the end of the list first: reverseList(head->next) returns the new head of the already-reversed remainder. - On the way back up the call stack, fix the link for the current node: head->next->next = head (point the next node back at the current one), then set head->next = null (this node is now the new tail of its local segment). - The base case is a null or single-node list, which is already "reversed" as-is. - O(n) time, O(n) space due to the recursive call stack - this is the key tradeoff versus the O(1)-space iterative version.

    Time / Space: O(n) time, O(n) space.

    public ListNode reverseList(ListNode head) {
    if (head == null || head.next == null) return head;
    ListNode reversedHead = reverseList(head.next);
    ListNode tail = head.next;
    tail.next = head;
    head.next = null;
    return reversedHead;
}

    11. Find the Length of the Loop in a Linked List

    Difficulty: MEDIUM

    Statement/Hint: Given a linked list that contains a cycle, find the number of nodes in the cycle (the loop's length).

    Example: - Input: head = 1→2→3→4→5, tail connects back to node with value 3 - Output: 3

    Approach: Floyd's Detection + Fixed-Point Counting - First detect the cycle using Floyd's slow/fast pointers until they meet at some node inside the loop. - From the meeting point, keep one pointer fixed and advance a second pointer one step at a time, counting steps, until it returns to the meeting point - that count is the loop's length. - O(n) time, O(1) space.

    Time / Space: O(n) time, O(1) space.

    private int findLength(ListNode slow, ListNode fast) {
    int count = 1;
    fast = fast.next;
    while (slow != fast) {
        fast = fast.next;
        count++;
    }
    return count;
}

public int countNodesInLoop(ListNode head) {
    ListNode slow = head, fast = head;
    while (fast != null && fast.next != null) {
        slow = slow.next;
        fast = fast.next.next;
        if (slow == fast) return findLength(slow, fast);
    }
    return 0;
}

    12. Odd Even Linked List

    Difficulty: MEDIUM

    Statement/Hint: Given a singly linked list, group all nodes at odd positions together followed by all nodes at even positions, without changing the relative order within each group and without using extra space for node values.

    Example: - Input: head = 1→2→3→4→5 - Output: 1→3→5→2→4

    Approach: In-Place Relinking (Two Chains) - Maintain two separate chains as you traverse: one collecting nodes at odd positions (1st, 3rd, 5th...) and one collecting nodes at even positions (2nd, 4th, 6th...), relinking existing nodes rather than copying values. - Track a pointer to the first even node before you start rewiring, since it's needed at the end to attach the tail of the odd chain to the head of the even chain. - After the single pass, splice the two chains together: the last odd node's next points to the first even node, and the last even node's next is set to null. - O(n) time, O(1) extra space - this beats a brute-force approach that copies values into odd/even arrays first (O(n) space).

    Time / Space: O(n) time, O(1) space.

    public ListNode oddEvenList(ListNode head) {
    if (head == null || head.next == null) return head;
    ListNode odd = head, even = head.next, evenHead = even;
    while (even != null && even.next != null) {
        odd.next = even.next;
        odd = odd.next;
        even.next = odd.next;
        even = even.next;
    }
    odd.next = evenHead;
    return head;
}

    13. Delete the Middle Node of a Linked List

    Difficulty: MEDIUM

    Statement/Hint: Delete the middle node of a singly linked list (for even length, delete the second of the two middle nodes) and return the head.

    Example: - Input: head = 1→2→3→4→5 - Output: 1→2→4→5

    Approach: Offset Slow/Fast Pointers - Use slow/fast pointers, but start fast two steps ahead of slow (fast = head->next->next) instead of both at head - this positions slow just before the true middle node when fast reaches the end. - Advance slow one step and fast two steps at a time until fast (or fast->next) is null; slow now sits at the node right before the one to delete. - Unlink the middle node via slow->next = slow->next->next. - O(n) time, O(1) space. Handle single/two-node list edge cases directly.

    Time / Space: O(n) time, O(1) space.

    public ListNode deleteMiddle(ListNode head) {
    if (head == null || head.next == null) return null;
    ListNode slow = head;
    ListNode fast = head.next.next;
    while (fast != null && fast.next != null) {
        fast = fast.next.next;
        slow = slow.next;
    }
    slow.next = slow.next.next;
    return head;
}

    14. Sort List

    Difficulty: MEDIUM

    Statement/Hint: Sort a singly linked list in ascending order in O(n log n) time and O(log n) space (excluding the input).

    Example: - Input: head = 4→2→1→3 - Output: 1→2→3→4

    Approach: Merge Sort on Linked List - Use merge sort adapted for linked lists: find the middle of the list (slow/fast pointers), split it into two halves, recursively sort each half, then merge the two sorted halves. - The merge step splices existing nodes together (using a dummy head and tail pointer) rather than allocating new nodes - the same technique as the standalone "merge two sorted linked lists" problem. - Unlike array merge sort, linked-list merge sort doesn't need O(n) auxiliary array space for merging - only the recursion stack costs O(log n). - O(n log n) time, O(log n) space for the recursion stack.

    Time / Space: O(n log n) time, O(log n) space.

    private ListNode findMiddle(ListNode head) {
    ListNode slow = head, fast = head.next;
    while (fast != null && fast.next != null) {
        slow = slow.next;
        fast = fast.next.next;
    }
    return slow;
}

private ListNode merge(ListNode l1, ListNode l2) {
    ListNode dummy = new ListNode(-1);
    ListNode temp = dummy;
    while (l1 != null && l2 != null) {
        if (l1.val <= l2.val) { temp.next = l1; l1 = l1.next; }
        else { temp.next = l2; l2 = l2.next; }
        temp = temp.next;
    }
    temp.next = (l1 != null) ? l1 : l2;
    return dummy.next;
}

public ListNode sortList(ListNode head) {
    if (head == null || head.next == null) return head;
    ListNode middle = findMiddle(head);
    ListNode right = middle.next;
    middle.next = null;
    ListNode left = sortList(head);
    right = sortList(right);
    return merge(left, right);
}

    15. Sort a Linked List of 0s, 1s and 2s

    Difficulty: MEDIUM

    Statement/Hint: Given a linked list containing only values 0, 1, and 2, sort it in a single pass by relinking nodes (not just swapping values).

    Example: - Input: head = 1→0→2→1→0 - Output: 0→0→1→1→2

    Approach: Three-Chain Relinking - Build three separate chains (using dummy heads) for 0s, 1s, and 2s, walking the original list once and appending each node to the appropriate chain based on its value. - After the single pass, splice the three chains together in order: the 0-chain's tail connects to the 1-chain's head (or the 2-chain's head if there are no 1s), the 1-chain's tail connects to the 2-chain's head, and the 2-chain's tail is set to null. - Handling an empty chain (e.g. no 1s) requires connecting the surrounding chains directly - this splicing logic is the main source of bugs. - O(n) time, O(1) extra space (only relinking existing nodes) - this beats a two-pass approach of counting occurrences and then overwriting node values.

    Time / Space: O(n) time, O(1) space.

    public ListNode sortZeroOneTwo(ListNode head) {
    ListNode dummy0 = new ListNode(-1), dummy1 = new ListNode(-1), dummy2 = new ListNode(-1);
    ListNode zero = dummy0, one = dummy1, two = dummy2;
    ListNode temp = head;
    while (temp != null) {
        ListNode nextNode = temp.next;
        if (temp.val == 0) { zero.next = temp; zero = temp; }
        else if (temp.val == 1) { one.next = temp; one = temp; }
        else { two.next = temp; two = temp; }
        temp.next = null;
        temp = nextNode;
    }
    zero.next = (dummy1.next != null) ? dummy1.next : dummy2.next;
    one.next = dummy2.next;
    return dummy0.next;
}

    16. Intersection of Two Linked Lists

    Difficulty: HIGH

    Statement/Hint: Given two singly linked lists that may intersect at some node (forming a Y shape), find the node where they intersect, or null if they don't.

    Example: - Input: listA = 4→1→8→4→5, listB = 5→6→1→8→4→5 (sharing the 8→4→5 tail) - Output: node with value 8

    Approach: Two-Pointer List Switching - Use two pointers, one starting at each list's head. Advance both one step at a time; when a pointer reaches the end of its list, redirect it to the head of the OTHER list. - Because both pointers together traverse (length of list A + length of list B) nodes before potentially meeting, they arrive at the intersection point at the same time - the extra distance from switching lists exactly cancels out the difference in list lengths. - If the lists don't intersect, both pointers reach null (having each traversed both lists) at the same time, ending the loop with a null result. - O(n + m) time, O(1) space - this beats a hash-set approach (marking all nodes of one list, then scanning the other) which costs O(n) space.

    Time / Space: O(n + m) time, O(1) space.

    public ListNode getIntersectionNode(ListNode headA, ListNode headB) {
    ListNode a = headA, b = headB;
    while (a != b) {
        a = (a != null) ? a.next : headB;
        b = (b != null) ? b.next : headA;
    }
    return a;
}

    17. Construct Linked List from Array

    Difficulty: LOW

    Statement/Hint: Given an array of values, construct a singly linked list from it and return its head.

    Example: - Input: arr = [1,2,3,4,5] - Output: head of 1→2→3→4→5

    Approach: Iterative Construction - Create the head node from the first array element, then iterate through the rest of the array, creating a new node for each value and linking it via the previous node's next pointer. - Maintain a temp pointer that always points to the last node added, so each new node can be attached in O(1) without re-traversing the list. - Return null immediately if the array is empty (no head to construct). - O(n) time, O(n) space for the n new nodes created.

    Time / Space: O(n) time, O(n) space.

    class Node {
    int data;
    Node next;
    Node(int x) { data = x; }
}

public Node constructLL(int[] arr) {
    if (arr.length == 0) return null;
    Node head = new Node(arr[0]);
    Node temp = head;
    for (int i = 1; i < arr.length; i++) {
        Node newNode = new Node(arr[i]);
        temp.next = newNode;
        temp = newNode;
    }
    return head;
}

    18. Add Two Numbers

    Difficulty: MEDIUM

    Statement/Hint: Two non-negative integers are represented as linked lists where each node holds a single digit in reverse order (least significant digit first). Add the two numbers and return the sum as a linked list in the same format.

    Example: - Input: l1 = 2→4→3 (342), l2 = 5→6→4 (465) - Output: 7→0→8 (807)

    Approach: Simultaneous Traversal with Carry - Since digits are already least-significant-first, no reversal is needed - walk both lists simultaneously from the head, adding corresponding digits plus any carry from the previous step. - Create a new node for each digit of the result (value = sum % 10), and carry the overflow (sum / 10) into the next iteration. - Continue as long as either list still has nodes OR there's a nonzero carry left - this naturally handles lists of different lengths and a final carry that extends the result by one digit. - Use a dummy head node to simplify result-list construction. O(max(n, m)) time, O(max(n, m)) space for the new result nodes.

    Time / Space: O(max(n, m)) time, O(max(n, m)) space.

    public ListNode addTwoNumbers(ListNode l1, ListNode l2) {
    ListNode dummy = new ListNode(-1);
    ListNode curr = dummy;
    int carry = 0;
    while (l1 != null || l2 != null || carry != 0) {
        int sum = carry;
        if (l1 != null) { sum += l1.val; l1 = l1.next; }
        if (l2 != null) { sum += l2.val; l2 = l2.next; }
        curr.next = new ListNode(sum % 10);
        curr = curr.next;
        carry = sum / 10;
    }
    return dummy.next;
}

    19. Delete All Occurrences of a Key in a Doubly Linked List

    Difficulty: LOW

    Statement/Hint: Given a doubly linked list and a key, delete every node whose value equals the key.

    Example: - Input: head = 10⇄20⇄10⇄30⇄10, key = 10 - Output: 20⇄30

    Approach: Dummy Node + In-Place Unlinking - Use a dummy node before the head to simplify deleting the head itself if it matches the key. - Walk the list once; whenever a node's value matches the key, unlink it by connecting its predecessor's next to its successor and the successor's prev back to the predecessor (checking each exists before dereferencing). - Because it's doubly linked, each deletion is O(1) once the node is found - no need to track a separate "previous" pointer manually, since prev is already stored on the node. - O(n) time, O(1) space.

    Time / Space: O(n) time, O(1) space.

    public DLLNode deleteAllOccurrences(DLLNode head, int k) {
    if (head == null) return null;
    DLLNode dummy = new DLLNode(-1);
    dummy.next = head;
    head.prev = dummy;
    DLLNode temp = head;
    while (temp != null) {
        if (temp.data == k) {
            DLLNode nextNode = temp.next;
            DLLNode prevNode = temp.prev;
            prevNode.next = nextNode;
            if (nextNode != null) nextNode.prev = prevNode;
            temp = nextNode;
        } else {
            temp = temp.next;
        }
    }
    DLLNode result = dummy.next;
    if (result != null) result.prev = null;
    return result;
}

    20. Find Pairs with Given Sum in a Doubly Linked List

    Difficulty: MEDIUM

    Statement/Hint: Given a sorted doubly linked list and a target sum, find all pairs of nodes whose values add up to the target.

    Example: - Input: head = 1⇄2⇄4⇄5⇄6⇄8⇄9, target = 7 - Output: (1,6), (2,5)

    Approach: Two Pointers from Both Ends - Use two pointers: one starting at the head, one starting at the tail (found by walking to the end once). - If the sum of the two pointers' values equals the target, record the pair and move both pointers inward (head forward via next, tail backward via prev). - If the sum is less than the target, move the head pointer forward (need a larger value); if greater, move the tail pointer backward (need a smaller value). - Stop when the pointers cross. O(n) time, O(1) extra space - this exploits the sorted order and the DLL's backward traversal ability, avoiding the O(n) space of a hash-set-based pair search.

    Time / Space: O(n) time, O(1) space.

    public List<int[]> findPairsWithGivenSum(DLLNode head, int target) {
    List<int[]> ans = new ArrayList<>();
    if (head == null || head.next == null) return ans;
    DLLNode tail = head;
    while (tail.next != null) tail = tail.next;
    while (head != tail && head.prev != tail) {
        int sum = head.data + tail.data;
        if (sum == target) {
            ans.add(new int[]{head.data, tail.data});
            head = head.next;
            tail = tail.prev;
        } else if (sum < target) {
            head = head.next;
        } else {
            tail = tail.prev;
        }
    }
    return ans;
}

    21. Remove Duplicates from a Sorted Doubly Linked List

    Difficulty: LOW

    Statement/Hint: Given a sorted doubly linked list, remove all duplicate values so each value appears only once.

    Example: - Input: head = 1⇄1⇄1⇄2⇄3⇄3 - Output: 1⇄2⇄3

    Approach: Adjacent Duplicate Skipping - Since the list is sorted, all duplicates of a value are guaranteed to be adjacent - walk the list once, comparing each node to its immediate successor(s). - For each node, keep advancing a lookahead pointer past any following nodes with the same value, then relink the current node directly to the first differing node (fixing both next and that node's prev). - No extra space is needed since duplicates are adjacent - this beats a hash-set approach that would work on unsorted lists too but costs O(n) space. - O(n) time, O(1) space.

    Time / Space: O(n) time, O(1) space.

    public DLLNode removeDuplicates(DLLNode head) {
    DLLNode temp = head;
    while (temp != null && temp.next != null) {
        DLLNode nextNode = temp.next;
        while (nextNode != null && nextNode.data == temp.data) {
            nextNode = nextNode.next;
        }
        temp.next = nextNode;
        if (nextNode != null) nextNode.prev = temp;
        temp = temp.next;
    }
    return head;
}

    22. Reverse Nodes in K-Group

    Difficulty: HIGH

    Statement/Hint: Given a singly linked list, reverse the nodes in groups of K at a time, and return the modified list. If the number of remaining nodes is less than K, leave that final group as-is.

    Example: - Input: head = 1→2→3→4→5, k = 2 - Output: 2→1→4→3→5

    Approach: Group-Bounded Reversal with Reconnection - For each group: first check if there are at least K nodes remaining by walking ahead - if not, stop and leave the rest untouched. - If a full group of K exists, reverse just that segment (standard in-place reversal, bounded to K nodes), then reconnect: the previous group's tail must point to the new head of this reversed group, and this group's new tail (the original first node) must point to the start of the next group. - Track whether this is the first group processed, since the very first reversed group's head becomes the new overall head. - O(n) time, O(1) space with a careful iterative implementation (or O(n/k) call-stack space if written recursively).

    Time / Space: O(n) time, O(1) space.

    private ListNode findKthNode(ListNode head, int k) {
    ListNode temp = head;
    for (int i = 0; i < k - 1 && temp != null; i++) temp = temp.next;
    return temp;
}

public ListNode reverseKGroup(ListNode head, int k) {
    ListNode temp = head, prevGroupTail = null, newHead = head;
    boolean first = true;
    while (temp != null) {
        ListNode kthNode = findKthNode(temp, k);
        if (kthNode == null) {
            if (prevGroupTail != null) prevGroupTail.next = temp;
            break;
        }
        ListNode nextGroupHead = kthNode.next;
        kthNode.next = null;
        ListNode prev = null, curr = temp;
        while (curr != null) {
            ListNode nxt = curr.next;
            curr.next = prev;
            prev = curr;
            curr = nxt;
        }
        if (first) { newHead = kthNode; first = false; }
        else prevGroupTail.next = kthNode;
        prevGroupTail = temp;
        temp = nextGroupHead;
    }
    return newHead;
}

    23. Rotate List

    Difficulty: MEDIUM

    Statement/Hint: Given a singly linked list and an integer K, rotate the list to the right by K places.

    Example: - Input: head = 1→2→3→4→5, k = 2 - Output: 4→5→1→2→3

    Approach: Find Split Point via Length - Find the list's length, then normalize K with k = k % length (rotating by the full length is a no-op). - Walk (length - k - 1) steps from the head to find the node that will become the new tail; the node after it becomes the new head. - Connect the original tail's next to the original head (temporarily forming a cycle conceptually), then break the list at the new tail by setting its next to null and returning the new head. - O(n) time, O(1) space - finding the split point via a single length calculation avoids needing separate logic for splitting and reattaching the list piece by piece.

    Time / Space: O(n) time, O(1) space.

    private int findLength(ListNode head) {
    int count = 1;
    while (head.next != null) {
        head = head.next;
        count++;
    }
    return count;
}

public ListNode rotateRight(ListNode head, int k) {
    if (head == null || head.next == null || k == 0) return head;
    int len = findLength(head);
    k = k % len;
    if (k == 0) return head;
    ListNode temp = head;
    for (int i = 0; i < len - k - 1; i++) temp = temp.next;
    ListNode newHead = temp.next;
    temp.next = null;
    ListNode newTail = newHead;
    while (newTail.next != null) newTail = newTail.next;
    newTail.next = head;
    return newHead;
}

    24. Flatten a Linked List

    Difficulty: MEDIUM

    Statement/Hint: Given a linked list where each node has a next pointer to the next list AND a bottom pointer to its own sorted sub-list, flatten it into a single sorted linked list using the bottom pointers.

    Example: - Input: five sorted sub-lists linked via top-level next, each with its own bottom chain - Output: one fully sorted linked list along bottom pointers

    Approach: Recursive Merge via Bottom Pointers - Process the sub-lists from right to left: recursively flatten everything to the right of the current node first, then merge the current node's bottom chain with that already-flattened result. - The merge step is identical to merging two sorted linked lists, except it operates on bottom pointers instead of next pointers. - Merging from right to left means each merge only ever combines two already-sorted lists (the current column and the accumulated flattened result), so the final output is fully sorted. - O(N) time where N is the total number of nodes across all sub-lists (each node is merged exactly once), O(number of top-level lists) space for the recursion stack.

    Time / Space: O(N) time, O(number of lists) space.

    private Node merge(Node a, Node b) {
    Node dummy = new Node(-1);
    Node temp = dummy;
    while (a != null && b != null) {
        if (a.data <= b.data) { temp.bottom = a; a = a.bottom; }
        else { temp.bottom = b; b = b.bottom; }
        temp = temp.bottom;
    }
    temp.bottom = (a != null) ? a : b;
    return dummy.bottom;
}

public Node flatten(Node root) {
    if (root == null || root.next == null) return root;
    Node mergedNext = flatten(root.next);
    return merge(root, mergedNext);
}

    25. Copy List with Random Pointer

    Difficulty: HIGH

    Statement/Hint: Given a linked list where each node has a next pointer and a random pointer (which may point to any node in the list or null), create a deep copy of the list.

    Example: - Input: head = [[7,null],[13,0],[11,4],[10,2],[1,0]] (val, random-index) - Output: a fully independent deep copy with equivalent next/random structure

    Approach: Interweaving Clones (O(1) Space) - Naive approach: use a hash map from original node -> cloned node. First pass creates all cloned nodes and populates the map; second pass wires each clone's next and random pointers by looking up the corresponding original node's pointers in the map. O(n) time, O(n) space. - Optimal O(1)-extra-space approach: interweave cloned nodes into the original list - for each original node, insert its clone immediately after it (original1 -> clone1 -> original2 -> clone2 -> ...). - With clones interwoven, each clone's random pointer can be set directly: clone->random = original->random->next (since the clone of any node is always immediately after that node). Then do a final pass to detach the interwoven clones into their own separate list, restoring the original list's structure. - O(n) time, O(1) extra space (excluding the output list itself) for the optimal approach - three total passes (insert clones, wire random pointers, detach).

    Time / Space: O(n) time, O(1) space.

    public Node copyRandomList(Node head) {
    if (head == null) return null;
    Node temp = head;
    while (temp != null) {
        Node newNode = new Node(temp.data);
        newNode.next = temp.next;
        temp.next = newNode;
        temp = newNode.next;
    }
    temp = head;
    while (temp != null) {
        if (temp.random != null) temp.next.random = temp.random.next;
        temp = temp.next.next;
    }
    Node dummy = new Node(-1);
    Node copyTemp = dummy;
    temp = head;
    while (temp != null) {
        copyTemp.next = temp.next;
        copyTemp = copyTemp.next;
        temp.next = temp.next.next;
        temp = temp.next;
    }
    return dummy.next;
}

    26. Add One to a Number Represented as a Linked List

    Difficulty: MEDIUM

    Statement/Hint: A number is represented as a linked list where each node holds one digit (most significant digit first). Add 1 to the number and return the resulting linked list.

    Example: - Input: head = 1→2→3 - Output: 1→2→4

    Approach: Reverse, Add with Carry, Reverse Back - Reverse the linked list first, so the least significant digit is now at the head - this makes adding 1 (which starts from the least significant digit) a simple forward traversal. - Walk the reversed list adding a carry (starting at 1): add the carry to each digit; if the result is < 10, the carry becomes 0 and you can stop early; otherwise set the digit to 0 and keep the carry as 1 for the next node. - If a carry remains after processing every node (e.g. 999 + 1 = 1000), prepend a new node with value 1 before reversing back. - Reverse the list again to restore the original most-significant-digit-first order. - O(n) time, O(1) extra space (aside from a possible new leading node) - this avoids converting to/from a numeric type, which would overflow for very large numbers.

    Time / Space: O(n) time, O(1) space.

    private ListNode reverseLL(ListNode head) {
    ListNode prev = null;
    while (head != null) {
        ListNode next = head.next;
        head.next = prev;
        prev = head;
        head = next;
    }
    return prev;
}

public ListNode addOne(ListNode head) {
    ListNode reversedHead = reverseLL(head);
    ListNode temp = reversedHead;
    int carry = 1;
    while (temp != null) {
        temp.val += carry;
        if (temp.val < 10) { carry = 0; break; }
        temp.val = 0;
        carry = 1;
        temp = temp.next;
    }
    ListNode result = reverseLL(reversedHead);
    if (carry == 1) {
        ListNode newHead = new ListNode(1);
        newHead.next = result;
        return newHead;
    }
    return result;
}

    27. Insert at Head of a Singly Linked List

    Difficulty: LOW

    Statement/Hint: Insert a new node with a given value at the head of a singly linked list, in O(1) time.

    Example: - Input: head = 2→3→4, insert 1 - Output: 1→2→3→4

    Approach: Direct Pointer Reassignment - Create a new node whose next pointer points to the current head, then update the head reference to point to this new node. - No traversal is needed - this is the one insertion position that doesn't require finding a predecessor node. - O(1) time, O(1) extra space (just the new node itself).

    Time / Space: O(1) time, O(1) space.

    public Node insertAtHead(Node head, int x) {
    Node newNode = new Node(x);
    newNode.next = head;
    return newNode;
}

    28. Delete Head of a Singly Linked List

    Difficulty: LOW

    Statement/Hint: Delete the head node of a singly linked list and return the new head.

    Example: - Input: head = 1→2→3→4 - Output: 2→3→4

    Approach: Direct Pointer Reassignment - The new head is simply the second node (head->next) - no searching or shifting is required. - Free/discard the old head node if the language requires manual memory management (e.g. C++); in garbage-collected languages this happens automatically once nothing references it. - Handle the empty-list edge case (head is null) by returning null. - O(1) time, O(1) space.

    Time / Space: O(1) time, O(1) space.

    public Node deleteHead(Node head) {
    if (head == null) return null;
    return head.next;
}

    29. Find the Length of a Linked List

    Difficulty: LOW

    Statement/Hint: Find the number of nodes in a singly linked list.

    Example: - Input: head = 1→2→3→4→5 - Output: 5

    Approach: Iterative Traversal - Walk the list from head to tail with a single pointer, incrementing a counter once per node visited. - Stop when the pointer becomes null (end of list reached). - O(n) time, O(1) space - a purely iterative traversal, though it can also be written recursively (count = 1 + length of rest) at the cost of O(n) call-stack space.

    Time / Space: O(n) time, O(1) space.

    public int getLength(Node head) {
    int count = 0;
    while (head != null) {
        head = head.next;
        count++;
    }
    return count;
}

    30. Search in a Linked List

    Difficulty: LOW

    Statement/Hint: Given a singly linked list and a key, determine whether the key exists in the list.

    Example: - Input: head = 1→2→3→4, key = 3 - Output: true

    Approach: Linear Traversal - Walk the list from head to tail, comparing each node's value to the key; return true as soon as a match is found. - Make sure the loop condition checks the current node itself (not just node->next), otherwise the last node in the list is silently skipped - a common off-by-one bug. - If the traversal reaches the end (null) without a match, return false. - O(n) time, O(1) space.

    Time / Space: O(n) time, O(1) space.

    public boolean searchKey(Node head, int key) {
    while (head != null) {
        if (head.data == key) return true;
        head = head.next;
    }
    return false;
}

    31. Construct Doubly Linked List from Array

    Difficulty: LOW

    Statement/Hint: Given an array of values, construct a doubly linked list from it and return its head.

    Example: - Input: arr = [1,2,3,4,5] - Output: head of doubly-linked 1⇄2⇄3⇄4⇄5

    Approach: Iterative Construction with Backward Links - Similar to constructing a singly linked list, but each new node's prev pointer must also be wired back to the previously created node. - Create the head from the first element, then for each subsequent element, create a new node, link the previous node's next to it, and link its own prev back to the previous node. - O(n) time, O(n) space for the n new nodes created.

    Time / Space: O(n) time, O(n) space.

    class DLLNode {
    int data;
    DLLNode next, prev;
    DLLNode(int x) { data = x; }
}

public DLLNode constructDLL(int[] arr) {
    DLLNode head = new DLLNode(arr[0]);
    DLLNode temp = head;
    for (int i = 1; i < arr.length; i++) {
        DLLNode newNode = new DLLNode(arr[i]);
        temp.next = newNode;
        newNode.prev = temp;
        temp = newNode;
    }
    return head;
}

    32. Insert Before Head of a Doubly Linked List

    Difficulty: LOW

    Statement/Hint: Insert a new node before the current head of a doubly linked list, making it the new head.

    Example: - Input: head = 2⇄3⇄4, insert 1 before head - Output: 1⇄2⇄3⇄4

    Approach: Direct Pointer Reassignment - Create the new node with its next pointer set to the current head, then set the current head's prev pointer to point back to the new node. - Update the head reference to the new node - no traversal needed since insertion happens at the very front. - O(1) time, O(1) extra space.

    Time / Space: O(1) time, O(1) space.

    public DLLNode insertBeforeHead(DLLNode head, int x) {
    DLLNode newNode = new DLLNode(x);
    newNode.next = head;
    if (head != null) head.prev = newNode;
    return newNode;
}
