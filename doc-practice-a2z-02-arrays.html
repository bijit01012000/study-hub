    1. Remove Duplicates from a Sorted Array

    Difficulty: MEDIUM

    Statement/Hint: Given a sorted array, remove duplicates in-place so each unique element appears once, and return the count of unique elements.

    Example: - Input: nums = [1, 1, 2, 2, 2, 3] - Output: 3 (array becomes [1, 2, 3, ...])

    Approach: Two Pointers - Use two pointers: i marks the last position of a confirmed-unique element, j scans ahead. - Because the array is sorted, duplicates of nums[i] are always adjacent - skip them while nums[j] == nums[i]. - When a new value is found, advance i and copy nums[j] into that slot. - The array is modified in-place with O(1) extra space; return i + 1 as the count of unique elements.

    Time / Space: O(n) time, O(1) space.

    public int removeDuplicates(int[] nums) {
    int i = 0;
    int n = nums.length;
    for (int j = 1; j < n; j++) {
        if (nums[j] == nums[i]) continue;
        i++;
        nums[i] = nums[j];
    }
    return i + 1;
}

    2. Left-Rotate an Array by D Places

    Difficulty: MEDIUM

    Statement/Hint: Left-rotate an array by d places in-place.

    Example: - Input: nums = [1, 2, 3, 4, 5, 6, 7], d = 2 - Output: [3, 4, 5, 6, 7, 1, 2]

    Approach: Reversal Algorithm - The reversal trick: to left-rotate by d, reverse the first d elements, reverse the remaining n-d elements, then reverse the whole array. - Reversing the two segments puts every element in reverse-of-target order within its segment; reversing the whole array then fixes the global order. - Always take d modulo n first, since rotating by n is a no-op and d can exceed n. - This achieves the rotation in-place with O(1) extra space instead of using a temporary array.

    Time / Space: O(n) time, O(1) space.

    public void rotate(int[] nums, int d) {
    int n = nums.length;
    d = d % n;
    reverseRange(nums, 0, d - 1);
    reverseRange(nums, d, n - 1);
    reverseRange(nums, 0, n - 1);
}

private void reverseRange(int[] nums, int lo, int hi) {
    while (lo < hi) {
        int tmp = nums[lo];
        nums[lo] = nums[hi];
        nums[hi] = tmp;
        lo++;
        hi--;
    }
}

    3. Move All Zeroes to the End

    Difficulty: HIGH

    Statement/Hint: Move all zeroes in an array to the end while keeping the relative order of non-zero elements, in-place.

    Example: - Input: nums = [0, 1, 0, 3, 12] - Output: [1, 3, 12, 0, 0]

    Approach: Two Pointers - Maintain a write pointer j that tracks where the next non-zero element should go. - Scan the array; whenever a non-zero element is found, place it at position j and increment j. - After the scan, positions from j to the end are the "leftover" slots - fill them with zero. - Relative order of non-zero elements is preserved because they are written in the order they were encountered.

    Time / Space: O(n) time, O(1) space.

    public void moveZeroes(int[] nums) {
    int n = nums.length;
    int j = 0;
    for (int i = 0; i < n; i++) {
        if (nums[i] != 0) {
            nums[j] = nums[i];
            j++;
        }
    }
    while (j < n) {
        nums[j] = 0;
        j++;
    }
}

    4. Linear Search

    Difficulty: LOW

    Statement/Hint: Given an array and a target value, find the index of the target using linear search.

    Example: - Input: nums = [5, 3, 8, 2], target = 8 - Output: 2

    Approach: Linear Scan - Scan the array from left to right, comparing each element to the target. - Return the index immediately on a match - no need to scan further. - Return -1 if the loop completes without finding the target. - No ordering assumption is needed, unlike binary search.

    Time / Space: O(n) time, O(1) space.

    public int linearSearch(int[] nums, int target) {
    for (int i = 0; i < nums.length; i++) {
        if (nums[i] == target) return i;
    }
    return -1;
}

    5. Union of Two Sorted Arrays

    Difficulty: MEDIUM

    Statement/Hint: Given two sorted arrays, find their union (all distinct elements from both, in sorted order).

    Example: - Input: arr1 = [1, 2, 3, 4, 5], arr2 = [2, 3, 4, 4, 5] - Output: [1, 2, 3, 4, 5]

    Approach: Two Pointers (Merge) - Use two pointers, one per array, and merge them like the merge step of merge sort. - At each step, advance whichever pointer has the smaller current element, and only append it to the result if it differs from the last appended value (to skip duplicates). - Once one array is exhausted, drain the rest of the other array the same way, still checking against the last appended value. - This produces the union in sorted order in a single linear pass over both arrays combined.

    Time / Space: O(n + m) time, O(n + m) space.

    public List<Integer> findUnion(int[] arr1, int[] arr2, int n, int m) {
    int i = 0, j = 0;
    List<Integer> union = new ArrayList<>();
    while (i < n && j < m) {
        if (arr1[i] <= arr2[j]) {
            if (union.isEmpty() || !union.get(union.size() - 1).equals(arr1[i]))
                union.add(arr1[i]);
            i++;
        } else {
            if (union.isEmpty() || !union.get(union.size() - 1).equals(arr2[j]))
                union.add(arr2[j]);
            j++;
        }
    }
    while (i < n) {
        if (!union.get(union.size() - 1).equals(arr1[i])) union.add(arr1[i]);
        i++;
    }
    while (j < m) {
        if (!union.get(union.size() - 1).equals(arr2[j])) union.add(arr2[j]);
        j++;
    }
    return union;
}

    6. Find the Missing Number

    Difficulty: MEDIUM

    Statement/Hint: An array contains n distinct numbers from 0 to n with one missing. Find the missing number.

    Example: - Input: nums = [3, 0, 1] - Output: 2

    Approach:

    Sort & Scan - Sorting approach: sort the array, then walk index by index - the first index whose value does not match the index is the missing number (handle the edge case where the last element is missing). - Both approaches sidestep overflow issues that a naive sum-based formula could hit for large n.

    Time / Space: O(n log n) time, O(1) space.

    public int missingNumber(int[] nums) {
    Arrays.sort(nums);
    for (int i = 0; i < nums.length; i++) {
        if (nums[i] != i) return i;
    }
    return nums.length;
}

    XOR - XOR approach: XOR all numbers from 0 to n together, then XOR that with all array elements - every present number cancels itself out (x ^ x = 0), leaving only the missing number. - The XOR approach avoids sorting and works in a single linear pass with constant extra space.

    Time / Space: O(n) time, O(1) space.

    public int missingNumber(int[] nums) {
    int n = nums.length;
    int xorOfAll = 0;
    int xorOfArray = 0;
    for (int i = 0; i <= n; i++) xorOfAll ^= i;
    for (int i = 0; i < n; i++) xorOfArray ^= nums[i];
    return xorOfAll ^ xorOfArray;
}

    7. Maximum Consecutive Ones

    Difficulty: LOW

    Statement/Hint: Find the maximum number of consecutive 1s in a binary array.

    Example: - Input: nums = [1, 1, 0, 1, 1, 1] - Output: 3

    Approach: Single Pass Counter - Keep a running counter of the current streak of 1s and a separate variable for the best streak seen so far. - Increment the counter on a 1 and update the max; reset the counter to 0 as soon as a 0 is seen. - A single pass suffices - no need to store positions or use extra data structures. - This is the simplest form of a "reset-on-break" sliding window.

    Time / Space: O(n) time, O(1) space.

    public int findMaxConsecutiveOnes(int[] nums) {
    int mx = 0;
    int cnt = 0;
    for (int num : nums) {
        if (num == 1) {
            cnt++;
            mx = Math.max(mx, cnt);
        } else {
            cnt = 0;
        }
    }
    return mx;
}

    8. Single Number

    Difficulty: MEDIUM

    Statement/Hint: Every element in an array appears twice except for one. Find the single element that appears only once.

    Example: - Input: nums = [4, 1, 2, 1, 2] - Output: 4

    Approach: XOR - XOR every element in the array together. - Because a ^ a = 0 and a ^ 0 = a, all paired elements cancel each other out regardless of order. - Whatever remains after XOR-ing the whole array is exactly the element that appeared only once. - This runs in one linear pass with no extra space, unlike a hashmap-count approach.

    Time / Space: O(n) time, O(1) space.

    public int singleNumber(int[] nums) {
    int ans = nums[0];
    for (int i = 1; i < nums.length; i++) {
        ans ^= nums[i];
    }
    return ans;
}

    9. Longest Subarray with Sum K (Positive Integers)

    Difficulty: MEDIUM

    Statement/Hint: Given an array of positive integers, find the length of the longest subarray whose sum equals K.

    Example: - Input: arr = [2, 3, 5, 1, 9], k = 10 - Output: 3 (subarray [2, 3, 5])

    Approach: Two Pointers / Sliding Window - Because all elements are positive, the running window sum only grows as the right edge extends and only shrinks as the left edge advances - this monotonic behavior is what makes a two-pointer sliding window valid. - Expand the window by moving right and adding to the sum; while the sum exceeds K, shrink from the left. - Whenever the sum exactly equals K, record the window length as a candidate answer. - This positives-only constraint is what allows an O(n) two-pointer solution; if negatives are allowed the window sum stops being monotonic and a prefix-sum hashmap is needed instead.

    Time / Space: O(2n) time, O(1) space.

    public int longestSubarray(int[] arr, int k) {
    int n = arr.length;
    int left = 0, right = 0;
    long sum = arr[0];
    int maxLen = 0;
    while (right < n) {
        while (left <= right && sum > k) {
            sum -= arr[left];
            left++;
        }
        if (sum == k) maxLen = Math.max(maxLen, right - left + 1);
        right++;
        if (right < n) sum += arr[right];
    }
    return maxLen;
}

    10. Two Sum

    Difficulty: HIGH

    Statement/Hint: Given an array and a target, determine if two numbers exist that add up to the target (and return them).

    Example: - Input: nums = [2, 7, 11, 15], target = 9 - Output: [0, 1]

    Approach:

    Hashmap - For each element, compute the complement (target - element) and check if it has already been seen; if so, the pair is found. Otherwise, record the current element and its index. - This works in one pass because by the time you reach the second number of a valid pair, its complement is already in the map. - Prefer the hashmap approach when original indices matter.

    Time / Space: O(n) time, O(n) space.

    public int[] twoSum(int[] nums, int target) {
    Map<Integer, Integer> mp = new HashMap<>();
    for (int i = 0; i < nums.length; i++) {
        int rem = target - nums[i];
        if (mp.containsKey(rem)) return new int[]{i, mp.get(rem)};
        mp.put(nums[i], i);
    }
    return new int[]{-1, -1};
}

    Two Pointers (sorted) - Sort the array, then move a left pointer up and a right pointer down based on whether the current sum is too small or too large. This costs O(n log n) due to sorting and only recovers values (not original indices) unless tracked separately. - Useful when the array is already sorted or only values are needed.

    Time / Space: O(n log n) time, O(1) space.

    public int[] twoSum(int[] nums, int target) {
    Arrays.sort(nums);
    int left = 0, right = nums.length - 1;
    while (left < right) {
        int sum = nums[left] + nums[right];
        if (sum == target) return new int[]{left, right};
        else if (sum < target) left++;
        else right--;
    }
    return new int[]{-1, -1};
}

    11. Sort an Array of 0s, 1s and 2s

    Difficulty: HIGH

    Statement/Hint: Sort an array containing only 0s, 1s, and 2s in a single pass, in-place.

    Example: - Input: nums = [2, 0, 1, 2, 1, 0] - Output: [0, 0, 1, 1, 2, 2]

    Approach:

    Counting Sort (two-pass) - Count occurrences of each value in one pass, then overwrite the array with that many 0s, then 1s, then 2s. Simple, but two passes.

    Time / Space: O(2n) time, O(1) space.

    public void sortColors(int[] nums) {
    int cnt0 = 0, cnt1 = 0, cnt2 = 0;
    for (int it : nums) {
        if (it == 0) cnt0++;
        else if (it == 1) cnt1++;
        else cnt2++;
    }
    int i = 0;
    for (; i < cnt0; i++) nums[i] = 0;
    for (; i < cnt0 + cnt1; i++) nums[i] = 1;
    for (; i < cnt0 + cnt1 + cnt2; i++) nums[i] = 2;
}

    Dutch National Flag (one-pass) - Maintain three pointers - low, mid, high - partitioning the array into [0s | 1s | unprocessed | 2s]. - If nums[mid] is 0, swap with low and advance both low and mid; if it is 1, just advance mid; if it is 2, swap with high and decrement high (do not advance mid, since the swapped-in value is unexamined). - The Dutch flag method sorts in a single pass with constant space, which is why it is the expected optimal answer.

    Time / Space: O(n) time, O(1) space.

    public void sortColors(int[] nums) {
    int low = 0, mid = 0, high = nums.length - 1;
    while (mid <= high) {
        if (nums[mid] == 0) {
            int tmp = nums[low]; nums[low] = nums[mid]; nums[mid] = tmp;
            low++; mid++;
        } else if (nums[mid] == 1) {
            mid++;
        } else {
            int tmp = nums[mid]; nums[mid] = nums[high]; nums[high] = tmp;
            high--;
        }
    }
}

    12. Majority Element (More Than n/2)

    Difficulty: HIGH

    Statement/Hint: Find the element that appears more than n/2 times in an array (guaranteed to exist).

    Example: - Input: nums = [2, 2, 1, 1, 1, 2, 2] - Output: 2

    Approach:

    Hashmap - Count occurrences of every element; as soon as a count exceeds n/2, that is the answer. Simple but uses O(n) extra space.

    Time / Space: O(n) time, O(n) space.

    public int majorityElement(int[] nums) {
    Map<Integer, Integer> mp = new HashMap<>();
    int n = nums.length;
    for (int i = 0; i < n; i++) {
        mp.merge(nums[i], 1, Integer::sum);
        if (mp.get(nums[i]) > n / 2) return nums[i];
    }
    return -1;
}

    Moore's Voting Algorithm - Maintain a candidate and a counter. If the counter hits 0, adopt the current element as the new candidate; increment the counter when the current element matches the candidate, decrement otherwise. - Because the majority element appears more than n/2 times, it can never be fully "cancelled out" by the other elements, so it survives as the final candidate. - A second pass confirms the candidate actually exceeds n/2 occurrences (needed when the problem does not guarantee a majority element exists).

    Time / Space: O(n) time, O(1) space.

    public int majorityElement(int[] nums) {
    int cnt = 0;
    int el = -1;
    int n = nums.length;
    for (int it : nums) {
        if (cnt == 0) {
            el = it;
            cnt = 1;
            continue;
        }
        if (it == el) cnt++;
        else cnt--;
    }
    cnt = 0;
    for (int it : nums) {
        if (it == el) cnt++;
    }
    return cnt > n / 2 ? el : -1;
}

    13. Maximum Subarray Sum (Kadane's Algorithm)

    Difficulty: HIGH

    Statement/Hint: Find the maximum sum of a contiguous subarray (Kadane's Algorithm).

    Example: - Input: nums = [-2, 1, -3, 4, -1, 2, 1, -5, 4] - Output: 6 (subarray [4, -1, 2, 1])

    Approach:

    Kadane's Algorithm - Keep a running sum as you scan the array, adding each element to it. - Whenever the running sum goes negative, reset it to 0 - a negative prefix can never help a future subarray, so it is better to start fresh from the next element. - Track the maximum running sum seen at any point - that is the answer.

    Time / Space: O(n) time, O(1) space.

    public int maxSubArray(int[] nums) {
    int sum = 0;
    int maxi = Integer.MIN_VALUE;
    for (int it : nums) {
        sum += it;
        if (sum > maxi) maxi = sum;
        if (sum < 0) sum = 0;
    }
    return maxi;
}

    With Start/End Indices - To recover the actual start/end indices, remember the index where the current run started (reset it whenever sum drops to 0) and update the answer indices whenever a new maximum is found.

    Time / Space: O(n) time, O(1) space.

    public int[] maxSubArrayIndices(int[] nums) {
    int sum = 0;
    int maxi = Integer.MIN_VALUE;
    int start = 0;
    int ansStart = -1, ansEnd = -1;
    for (int i = 0; i < nums.length; i++) {
        if (sum == 0) start = i;
        sum += nums[i];
        if (sum > maxi) {
            maxi = sum;
            ansStart = start;
            ansEnd = i;
        }
        if (sum < 0) sum = 0;
    }
    return new int[]{ansStart, ansEnd};
}

    14. Best Time to Buy and Sell Stock

    Difficulty: HIGH

    Statement/Hint: Given an array of stock prices by day, find the maximum profit from a single buy and a single sell (buy before sell).

    Example: - Input: prices = [7, 1, 5, 3, 6, 4] - Output: 5

    Approach: Single Pass (Track Min) - Track the minimum price seen so far while scanning left to right - this represents the best possible buy day up to the current point. - At each day, compute the profit if you sold today (current price minus the minimum-so-far) and update the best profit. - Update the minimum-so-far after checking the profit, since you cannot sell on the same day you buy. - A single linear pass suffices - no need to check every buy/sell pair explicitly.

    Time / Space: O(n) time, O(1) space.

    public int maxProfit(int[] prices) {
    int minUntilIndex = prices[0];
    int mxProfit = 0;
    for (int i = 0; i < prices.length; i++) {
        mxProfit = Math.max(mxProfit, prices[i] - minUntilIndex);
        minUntilIndex = Math.min(prices[i], minUntilIndex);
    }
    return mxProfit;
}

    15. Rearrange Array by Sign

    Difficulty: MEDIUM

    Statement/Hint: Given an array with an equal number of positive and negative elements, rearrange it so positive and negative numbers alternate, starting with positive, preserving relative order within each sign.

    Example: - Input: nums = [3, 1, -2, -5, 2, -4] - Output: [3, -2, 1, -5, 2, -4]

    Approach: Two Write Pointers - Allocate a result array of the same size, and use two write pointers: one for even (positive) indices starting at 0, one for odd (negative) indices starting at 1. - Scan the original array once; place each positive number at the next even slot and each negative number at the next odd slot. - Because each write pointer only moves within its own sign's slots, relative order within positives and within negatives is preserved automatically. - This assumes equal counts of positives and negatives so both pointer sequences fill the array exactly.

    Time / Space: O(n) time, O(n) space.

    public int[] rearrangeArray(int[] nums) {
    int posIndex = 0;
    int negIndex = 1;
    int n = nums.length;
    int[] ans = new int[n];
    for (int i = 0; i < n; i++) {
        if (nums[i] < 0) {
            ans[negIndex] = nums[i];
            negIndex += 2;
        } else {
            ans[posIndex] = nums[i];
            posIndex += 2;
        }
    }
    return ans;
}

    16. Next Permutation

    Difficulty: HIGH

    Statement/Hint: Rearrange an array of numbers into the lexicographically next greater permutation, in-place. If no such permutation exists, rearrange to the lowest possible order.

    Example: - Input: nums = [1, 2, 3] - Output: [1, 3, 2]

    Approach: In-Place Break-Point Swap - Scan from the right to find the first index (the "break point") where nums[i] < nums[i+1] - this marks the longest non-increasing suffix. - If no such index exists, the array is the last permutation (fully descending); reverse the whole array to wrap around to the first permutation. - Otherwise, scan from the right again to find the smallest element greater than nums[breakIndex] and swap it with nums[breakIndex]. - Finally, reverse everything after breakIndex - since that suffix was non-increasing, reversing makes it the smallest possible arrangement, giving the immediate next permutation.

    Time / Space: O(n) time, O(1) space.

    public void nextPermutation(int[] nums) {
    int brkIndex = -1;
    int n = nums.length;
    for (int i = n - 2; i >= 0; i--) {
        if (nums[i] < nums[i + 1]) {
            brkIndex = i;
            break;
        }
    }
    if (brkIndex == -1) {
        reverseRange(nums, 0, n - 1);
        return;
    }
    int justGreaterIndex = -1;
    for (int i = n - 1; i >= 0; i--) {
        if (nums[i] > nums[brkIndex]) {
            justGreaterIndex = i;
            break;
        }
    }
    int tmp = nums[brkIndex]; nums[brkIndex] = nums[justGreaterIndex]; nums[justGreaterIndex] = tmp;
    reverseRange(nums, brkIndex + 1, n - 1);
}

private void reverseRange(int[] nums, int lo, int hi) {
    while (lo < hi) {
        int tmp = nums[lo];
        nums[lo] = nums[hi];
        nums[hi] = tmp;
        lo++;
        hi--;
    }
}

    17. Leaders in an Array

    Difficulty: LOW

    Statement/Hint: Find all "leaders" in an array - elements that are strictly greater than every element to their right.

    Example: - Input: nums = [10, 22, 12, 3, 0, 6] - Output: [22, 12, 6]

    Approach: Right-to-Left Scan - Scan the array from right to left, keeping track of the maximum seen so far. - The last element is always a leader (nothing to its right). - Any element strictly greater than the current running max is also a leader; update the running max when found. - Since leaders are discovered right-to-left, reverse the collected list at the end to return them in original left-to-right order.

    Time / Space: O(n) time, O(n) space.

    public List<Integer> leaders(int[] nums) {
    List<Integer> ans = new ArrayList<>();
    int n = nums.length;
    ans.add(nums[n - 1]);
    int mxOnRight = nums[n - 1];
    for (int i = n - 2; i >= 0; i--) {
        if (nums[i] > mxOnRight) {
            ans.add(nums[i]);
            mxOnRight = nums[i];
        }
    }
    Collections.reverse(ans);
    return ans;
}

    18. Longest Consecutive Sequence

    Difficulty: HIGH

    Statement/Hint: Given an unsorted array of integers, find the length of the longest run of consecutive integers (e.g. [100,4,200,1,3,2] gives 4, for the run 1,2,3,4).

    Example: - Input: nums = [100, 4, 200, 1, 3, 2] - Output: 4 (the run 1, 2, 3, 4)

    Approach:

    Sorting - Sort the array, then scan once, extending a streak when the next element is exactly one more than the previous, resetting on a gap, and skipping over exact duplicates.

    Time / Space: O(n log n) time, O(1) space.

    public int longestConsecutive(int[] arr) {
    Arrays.sort(arr);
    int cnt = 1;
    int mxCnt = 1;
    for (int i = 1; i < arr.length; i++) {
        if (arr[i - 1] + 1 == arr[i]) {
            cnt++;
            mxCnt = Math.max(cnt, mxCnt);
        } else if (arr[i - 1] == arr[i]) {
            continue;
        } else {
            cnt = 1;
        }
    }
    return mxCnt;
}

    Hash Set - Insert all elements into a set, then for each element check if it is the start of a sequence (i.e. element - 1 is not in the set). - Only starting elements trigger an inner while-loop that walks forward counting the streak length - this ensures every element is visited only twice total across the whole algorithm, keeping it linear. - The hash set approach avoids the O(n log n) sort, achieving true O(n) time at the cost of O(n) extra space.

    Time / Space: O(n) time, O(n) space.

    public int longestConsecutive(int[] arr) {
    Set<Integer> s = new HashSet<>();
    for (int it : arr) s.add(it);
    int mxCnt = 1;
    for (int it : arr) {
        if (!s.contains(it - 1)) {
            int cnt = 1;
            int curr = it;
            while (s.contains(curr + 1)) {
                cnt++;
                curr++;
            }
            mxCnt = Math.max(cnt, mxCnt);
        }
    }
    return mxCnt;
}

    19. Set Matrix Zeroes

    Difficulty: HIGH

    Statement/Hint: Given an m x n matrix, if an element is 0, set its entire row and column to 0, in-place.

    Example: - Input: matrix = [[1,1,1],[1,0,1],[1,1,1]] - Output: [[1,0,1],[0,0,0],[1,0,1]]

    Approach:

    Extra Row/Col Arrays - Use auxiliary row[] and col[] boolean arrays to mark which rows/columns contain a zero, then zero out any cell whose row or column was marked.

    Time / Space: O(n*m) time, O(n + m) space.

    public void setZeroes(int[][] matrix) {
    int n = matrix.length;
    int m = matrix[0].length;
    int[] row = new int[n];
    int[] col = new int[m];
    Arrays.fill(row, 1);
    Arrays.fill(col, 1);
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < m; j++) {
            if (matrix[i][j] == 0) {
                row[i] = 0;
                col[j] = 0;
            }
        }
    }
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < m; j++) {
            if (row[i] == 0 || col[j] == 0) matrix[i][j] = 0;
        }
    }
}

    In-Place (first row/col as markers) - Optimal in-place approach: reuse the matrix's own first row and first column as the marker arrays instead of allocating new ones, using a separate flag (row0) for whether the first row itself needs zeroing (since matrix[0][0] does double duty as the first column's marker). - First pass: for every zero found (outside the first row), mark matrix[i][0] and matrix[0][j]; if the zero is in the first row, set row0 = 0 instead. - Second pass (excluding row/col 0): zero out any cell whose row-marker or column-marker is set, then finally zero out the first column (based on matrix[0][0]) and first row (based on row0).

    Time / Space: O(n*m) time, O(1) space.

    public void setZeroes(int[][] matrix) {
    int n = matrix.length;
    int m = matrix[0].length;
    int row0 = 1;
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < m; j++) {
            if (matrix[i][j] == 0) {
                if (i == 0) row0 = 0;
                else {
                    matrix[i][0] = 0;
                    matrix[0][j] = 0;
                }
            }
        }
    }
    for (int i = 1; i < n; i++) {
        for (int j = 1; j < m; j++) {
            if (matrix[i][0] == 0 || matrix[0][j] == 0) matrix[i][j] = 0;
        }
    }
    if (matrix[0][0] == 0) {
        for (int i = 0; i < n; i++) matrix[i][0] = 0;
    }
    if (row0 == 0) {
        for (int i = 0; i < m; i++) matrix[0][i] = 0;
    }
}

    20. Rotate Matrix by 90 Degrees

    Difficulty: MEDIUM

    Statement/Hint: Rotate an n x n matrix by 90 degrees clockwise, in-place.

    Example: - Input: matrix = [[1,2,3],[4,5,6],[7,8,9]] - Output: [[7,4,1],[8,5,2],[9,6,3]]

    Approach: Transpose + Reverse Rows - Break the rotation into two simpler in-place operations: transpose, then reverse each row. - Transpose swaps matrix[i][j] with matrix[j][i] for all i < j, converting rows into columns. - Reversing each row after transposing completes the clockwise rotation (transpose + reverse rows = rotate right; transpose + reverse columns would give counter-clockwise). - Both steps operate in-place with no extra matrix needed.

    Time / Space: O(n^2) time, O(1) space.

    public void rotate(int[][] matrix) {
    int n = matrix.length;
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < i; j++) {
            int tmp = matrix[i][j];
            matrix[i][j] = matrix[j][i];
            matrix[j][i] = tmp;
        }
    }
    for (int i = 0; i < n; i++) {
        int lo = 0, hi = n - 1;
        while (lo < hi) {
            int tmp = matrix[i][lo];
            matrix[i][lo] = matrix[i][hi];
            matrix[i][hi] = tmp;
            lo++;
            hi--;
        }
    }
}

    21. Spiral Traversal of a Matrix

    Difficulty: MEDIUM

    Statement/Hint: Given an m x n matrix, return all elements in spiral order (clockwise, from the outside in).

    Example: - Input: matrix = [[1,2,3],[4,5,6],[7,8,9]] - Output: [1, 2, 3, 6, 9, 8, 7, 4, 5]

    Approach: Boundary Simulation - Maintain four boundaries: top, bottom, left, right, and shrink them as each side is fully traversed. - Traverse the top row left-to-right, then the right column top-to-bottom, then (if boundaries still valid) the bottom row right-to-left, then the left column bottom-to-top. - After each side, move the corresponding boundary inward (top++, right--, bottom--, left++). - The guards (top <= bottom, left <= right) before the bottom-row and left-column traversals prevent re-visiting cells when the remaining region is a single row or column.

    Time / Space: O(n*m) time, O(n*m) output space.

    public List<Integer> spiralOrder(int[][] matrix) {
    int n = matrix.length;
    int m = matrix[0].length;
    int top = 0, bottom = n - 1, left = 0, right = m - 1;
    List<Integer> ans = new ArrayList<>();
    while (top <= bottom && left <= right) {
        for (int i = left; i <= right; i++) ans.add(matrix[top][i]);
        top++;
        for (int i = top; i <= bottom; i++) ans.add(matrix[i][right]);
        right--;
        if (top <= bottom) {
            for (int i = right; i >= left; i--) ans.add(matrix[bottom][i]);
            bottom--;
        }
        if (left <= right) {
            for (int i = bottom; i >= top; i--) ans.add(matrix[i][left]);
            left++;
        }
    }
    return ans;
}

    22. Count Subarrays with Sum K

    Difficulty: MEDIUM

    Statement/Hint: Given an array (possibly with negative numbers) and a target sum, count the number of subarrays that sum to exactly the target.

    Example: - Input: nums = [1, 2, 3, -3, 4], k = 3 - Output: 3

    Approach: Prefix Sum + Hashmap - Maintain a running prefix sum and a hashmap of (prefix sum value -> how many times it has occurred so far). - For the current prefix sum, the subarray ending here sums to the target if some earlier prefix sum equals (currentPrefixSum - target); the count of such earlier prefixes is added directly to the answer. - Initialize the map with {0: 1} before scanning - this accounts for subarrays that start from index 0 and already equal the target. - Because negatives are allowed, a sliding window will not work here (sums are not monotonic) - the prefix-sum hashmap is the general-purpose technique.

    Time / Space: O(n) time, O(n) space.

    public int subarraySum(int[] nums, int k) {
    int n = nums.length;
    int preSum = 0;
    int cnt = 0;
    Map<Integer, Integer> mp = new HashMap<>();
    mp.put(0, 1);
    for (int i = 0; i < n; i++) {
        preSum += nums[i];
        int rem = preSum - k;
        cnt += mp.getOrDefault(rem, 0);
        mp.merge(preSum, 1, Integer::sum);
    }
    return cnt;
}

    23. Pascal's Triangle

    Difficulty: LOW

    Statement/Hint: Generate the first numRows rows of Pascal's Triangle.

    Example: - Input: numRows = 5 - Output: [[1],[1,1],[1,2,1],[1,3,3,1],[1,4,6,4,1]]

    Approach: Incremental Binomial Coefficient - Each row i has i+1 entries; the value at column j is the binomial coefficient C(i, j). - Rather than computing factorials, build each entry incrementally from the previous one in the same row: C(i, j+1) = C(i, j) * (i - j) / (j + 1). - Start each row with 1 (C(i, 0) = 1) and apply the incremental formula across the row. - This avoids both the O(row) recomputation of a naive "sum of the two above" approach per cell and factorial overflow issues.

    Time / Space: O(numRows^2) time, O(1) extra space.

    public List<List<Integer>> generate(int numRows) {
    List<List<Integer>> ans = new ArrayList<>();
    for (int i = 0; i < numRows; i++) {
        List<Integer> temp = new ArrayList<>();
        int icj = 1;
        for (int j = 0; j <= i; j++) {
            temp.add(icj);
            icj = (icj * (i - j)) / (j + 1);
        }
        ans.add(temp);
    }
    return ans;
}

    24. Majority Element (More Than n/3)

    Difficulty: MEDIUM

    Statement/Hint: Find all elements that appear more than n/3 times in an array (there can be at most two such elements).

    Example: - Input: nums = [1, 1, 1, 3, 3, 2, 2, 2] - Output: [1, 2]

    Approach: Extended Boyer-Moore Voting - Since "more than n/3" means at most 2 elements can satisfy the condition, extend Moore's Voting to track two candidates and two counters simultaneously. - For each element: if it matches an existing candidate, bump that candidate's counter; else if a candidate's counter is 0, claim that slot for the current element; otherwise, decrement both counters (the element "cancels" one vote from each candidate). - The order of checks matters - always try to increment a matching candidate's count before considering claiming an empty slot, so an element already assigned to el2 does not get reassigned to el1 as well. - A final pass counts actual occurrences of both candidates and confirms which (if any) truly exceed n/3, since surviving the voting phase does not guarantee the threshold is met.

    Time / Space: O(n) time, O(1) space.

    public List<Integer> majorityElement(int[] nums) {
    int cnt1 = 0, cnt2 = 0;
    int el1 = Integer.MIN_VALUE, el2 = Integer.MIN_VALUE;
    int n = nums.length;
    for (int it : nums) {
        if (cnt1 == 0 && el2 != it) {
            el1 = it;
            cnt1 = 1;
        } else if (cnt2 == 0 && el1 != it) {
            el2 = it;
            cnt2 = 1;
        } else if (it == el1) cnt1++;
        else if (it == el2) cnt2++;
        else {
            cnt1--;
            cnt2--;
        }
    }
    List<Integer> ans = new ArrayList<>();
    cnt1 = 0; cnt2 = 0;
    for (int it : nums) {
        if (it == el1) cnt1++;
        else if (it == el2) cnt2++;
    }
    int mini = n / 3 + 1;
    if (cnt1 >= mini) ans.add(el1);
    if (cnt2 >= mini) ans.add(el2);
    return ans;
}

    25. Three Sum

    Difficulty: HIGH

    Statement/Hint: Find all unique triplets in an array that sum to zero.

    Example: - Input: nums = [-1, 0, 1, 2, -1, -4] - Output: [[-1,-1,2],[-1,0,1]]

    Approach:

    Brute Force + Set - Check every triplet with three nested loops, and use a set of sorted triplets to filter out duplicates.

    Time / Space: O(n^3 log n) time, O(n) space.

    public List<List<Integer>> threeSum(int[] nums) {
    int n = nums.length;
    Set<List<Integer>> s = new TreeSet<>((a, b) -> {
        for (int i = 0; i < 3; i++) if (!a.get(i).equals(b.get(i))) return a.get(i) - b.get(i);
        return 0;
    });
    for (int i = 0; i < n; i++) {
        for (int j = i + 1; j < n; j++) {
            for (int k = j + 1; k < n; k++) {
                if (nums[i] + nums[j] + nums[k] == 0) {
                    List<Integer> temp = new ArrayList<>(List.of(nums[i], nums[j], nums[k]));
                    Collections.sort(temp);
                    s.add(temp);
                }
            }
        }
    }
    return new ArrayList<>(s);
}

    Sort + Two Pointers - Sort the array first, fix the first element i, then use two pointers (j starting right after i, k at the end) to find pairs summing to -nums[i]. - Skip over duplicate values for i (and for j/k after finding a valid triplet) to avoid emitting the same triplet twice - this is only safe because the array is sorted. - Move j forward when the running sum is too small, k backward when too large, and shrink both inward together after recording a match.

    Time / Space: O(n^2) time, O(1) space excluding output.

    public List<List<Integer>> threeSum(int[] nums) {
    int n = nums.length;
    List<List<Integer>> ans = new ArrayList<>();
    Arrays.sort(nums);
    for (int i = 0; i < n; i++) {
        if (i != 0 && nums[i] == nums[i - 1]) continue;
        int j = i + 1;
        int k = n - 1;
        while (j < k) {
            int sum = nums[i] + nums[j] + nums[k];
            if (sum < 0) j++;
            else if (sum > 0) k--;
            else {
                ans.add(List.of(nums[i], nums[j], nums[k]));
                j++; k--;
                while (j < k && nums[j] == nums[j - 1]) j++;
                while (j < k && nums[k] == nums[k + 1]) k--;
            }
        }
    }
    return ans;
}

    26. Four Sum

    Difficulty: MEDIUM

    Statement/Hint: Find all unique quadruplets in an array that sum to a given target.

    Example: - Input: nums = [1, 0, -1, 0, -2, 2], target = 0 - Output: [[-2,-1,1,2],[-2,0,0,2],[-1,0,0,1]]

    Approach: Sort + Nested Two Pointers - Sort the array first so duplicate skipping and two-pointer logic both become possible. - Fix the first two elements with nested loops (i and j), skipping duplicate values at each level to avoid repeated quadruplets. - For the remaining two elements, use two pointers (k just after j, l at the array's end) converging based on whether the running total (using a wider integer type to avoid overflow) is below, above, or equal to the target. - On a match, record the quadruplet and skip duplicate values for both k and l before continuing to shrink the pointers inward.

    Time / Space: O(n^3) time, O(1) space excluding output.

    public List<List<Integer>> fourSum(int[] nums, int target) {
    int n = nums.length;
    List<List<Integer>> ans = new ArrayList<>();
    Arrays.sort(nums);
    for (int i = 0; i < n; i++) {
        if (i != 0 && nums[i] == nums[i - 1]) continue;
        for (int j = i + 1; j < n; j++) {
            if (j != i + 1 && nums[j] == nums[j - 1]) continue;
            int k = j + 1;
            int l = n - 1;
            while (k < l) {
                long sum = (long) nums[i] + nums[j] + nums[k] + nums[l];
                if (sum < target) k++;
                else if (sum > target) l--;
                else {
                    ans.add(List.of(nums[i], nums[j], nums[k], nums[l]));
                    k++; l--;
                    while (k < l && nums[k] == nums[k - 1]) k++;
                    while (k < l && nums[l] == nums[l + 1]) l--;
                }
            }
        }
    }
    return ans;
}

    27. Longest Subarray with Sum K (with Negatives)

    Difficulty: MEDIUM

    Statement/Hint: Given an array that may contain negative numbers, find the length of the longest subarray whose sum equals K.

    Example: - Input: nums = [-1, 1, 1], k = 1 - Output: 3 (subarray [-1, 1, 1])

    Approach: Prefix Sum + Hashmap (first-occurrence index) - Because negatives can appear, the running prefix sum is no longer monotonic, so the positives-only two-pointer trick does not apply - use a prefix-sum hashmap instead. - Maintain a running prefix sum and a map from prefix-sum value to the earliest index it was seen at (only the first occurrence is stored, since we want the longest subarray). - At each index, if (prefixSum - K) has been seen before, the subarray between that earlier index and now sums to K; update the max length using the earliest such index. - Seed the map with {0: -1} so a subarray starting at index 0 (where prefixSum itself equals K) is handled by the same general lookup instead of a special case.

    Time / Space: O(n) time, O(n) space.

    public int longestSubarray(int[] arr, int k) {
    Map<Integer, Integer> mp = new HashMap<>();
    int n = arr.length;
    int preSum = 0;
    int mxLen = 0;
    mp.put(0, -1);
    for (int i = 0; i < n; i++) {
        preSum += arr[i];
        int rem = preSum - k;
        if (mp.containsKey(rem)) mxLen = Math.max(mxLen, i - mp.get(rem));
        mp.putIfAbsent(preSum, i);
    }
    return mxLen;
}

    28. Count Subarrays with XOR K

    Difficulty: MEDIUM

    Statement/Hint: Given an array and an integer K, count the number of subarrays whose XOR equals K.

    Example: - Input: nums = [4, 2, 2, 6, 4], k = 6 - Output: 4

    Approach: Prefix XOR + Hashmap - Maintain a running prefix XOR and a hashmap of (prefix XOR value -> how many times it has occurred so far). - For the subarray ending at the current index to have XOR K, some earlier prefix XOR must equal (currentPrefixXor XOR K) - since XOR-ing out the earlier prefix isolates exactly the subarray XOR (a ^ a = 0). - Add the count of that earlier prefix-XOR value directly to the running answer, then record the current prefix XOR in the map. - Initialize the map with {0: 1} to correctly count subarrays that start at index 0.

    Time / Space: O(n) time, O(n) space.

    public long subarrayXor(int[] arr, int k) {
    int sum = 0;
    Map<Integer, Integer> mp = new HashMap<>();
    long cnt = 0;
    mp.put(sum, 1);
    for (int it : arr) {
        sum ^= it;
        int rem = sum ^ k;
        cnt += mp.getOrDefault(rem, 0);
        mp.merge(sum, 1, Integer::sum);
    }
    return cnt;
}

    29. Longest Subarray with Sum 0

    Difficulty: MEDIUM

    Statement/Hint: Find the length of the longest subarray whose elements sum to 0.

    Example: - Input: nums = [15, -2, 2, -8, 1, 7, 10, 23] - Output: 5 (subarray [-2, 2, -8, 1, 7])

    Approach: Prefix Sum + Hashmap (first-occurrence index) - This is the K=0 special case of the general prefix-sum + hashmap technique, but tracking length instead of count. - Maintain a running prefix sum and a map from prefix-sum value to the first index it was seen at. - If the prefix sum itself is 0 at the current index, the subarray from the start up to here sums to 0 - update the max length directly with (index + 1). - Otherwise, if the current prefix sum has been seen before, the subarray between that earlier index and now sums to 0 - update max length using the earliest recorded index for that sum.

    Time / Space: O(n) time, O(n) space.

    public int maxLen(int[] arr) {
    int preSum = 0;
    int mxLen = 0;
    int n = arr.length;
    Map<Integer, Integer> mp = new HashMap<>();
    for (int i = 0; i < n; i++) {
        preSum += arr[i];
        if (preSum == 0) mxLen = Math.max(mxLen, i + 1);
        else {
            if (mp.containsKey(preSum)) mxLen = Math.max(mxLen, i - mp.get(preSum));
            else mp.put(preSum, i);
        }
    }

}

    30. Merge Overlapping Intervals

    Difficulty: HIGH

    Statement/Hint: Given a collection of intervals, merge all overlapping intervals and return the resulting non-overlapping set.

    Example: - Input: intervals = [[1,3],[2,6],[8,10],[15,18]] - Output: [[1,6],[8,10],[15,18]]

    Approach: Sort + Linear Merge - Sort the intervals by start time first - this guarantees that any interval that could overlap with the current merged group must come immediately after it in the sorted order. - Walk through the sorted intervals, comparing each to the last interval placed in the answer list. - If the current interval's start is greater than the last placed interval's end, there is no overlap - push it as a new interval. - Otherwise, they overlap - merge them by extending the last placed interval's end to the max of the two ends (the start does not need updating since intervals are processed in sorted-start order).

    Time / Space: O(n log n) time, O(n) space.

    public int[][] merge(int[][] intervals) {
    Arrays.sort(intervals, (a, b) -> a[0] - b[0]);
    List<int[]> ans = new ArrayList<>();
    for (int[] it : intervals) {
        if (ans.isEmpty() || it[0] > ans.get(ans.size() - 1)[1]) {
            ans.add(it);
        } else {
            ans.get(ans.size() - 1)[1] = Math.max(ans.get(ans.size() - 1)[1], it[1]);
        }
    }
    return ans.toArray(new int[0][]);
}

    31. Merge Two Sorted Arrays Without Extra Space

    Difficulty: MEDIUM

    Statement/Hint: Given two sorted arrays (of possibly different sizes, with no extra array allowed), merge them in-place so both end up sorted.

    Example: - Input: arr1 = [1, 4, 8, 10], arr2 = [2, 3, 9] - Output: arr1 = [1, 2, 3, 4], arr2 = [8, 9, 10]

    Approach:

    Two-Pointer Swap + Individual Sort - Point one pointer at the end of the first array and one at the start of the second; while the first array's element is bigger, swap them and move both pointers inward. Then sort each array individually to fix any remaining local disorder. - This works because after the swap phase, every element in array 1 is guaranteed <= every element in array 2, but the per-array sort still costs O(n log n + m log m).

    Time / Space: O((n+m) log(n+m)) time, O(1) space.

    public void merge(long[] arr1, long[] arr2, int n, int m) {
    int left = n - 1;
    int right = 0;
    while (left >= 0 && right < m) {
        if (arr1[left] > arr2[right]) {
            long tmp = arr1[left];
            arr1[left] = arr2[right];
            arr2[right] = tmp;
            left--; right++;
        } else {
            break;
        }
    }
    Arrays.sort(arr1);
    Arrays.sort(arr2);
}

    Gap Method (Shell Sort style) - Treat both arrays as one combined logical array of length n+m, and use a shrinking gap (like Shell Sort) starting at ceil((n+m)/2), comparing and swapping elements gap apart across the combined array, halving the gap each round until it reaches 1. - The gap method achieves O((n+m) log(n+m)) time with true O(1) extra space, since it never needs a full sort - just log(n+m) comparison passes.

    Time / Space: O((n+m) log(n+m)) time, O(1) space.

    public void merge(long[] arr1, long[] arr2, int n, int m) {
    int len = n + m;
    int gap = (len / 2) + (len % 2);
    while (gap > 0) {
        int left = 0, right = left + gap;
        while (right < len) {
            if (left < n && right < n) {
                if (arr1[left] > arr1[right]) {
                    long tmp = arr1[left]; arr1[left] = arr1[right]; arr1[right] = tmp;
                }
            } else if (left < n && right >= n) {
                if (arr1[left] > arr2[right - n]) {
                    long tmp = arr1[left]; arr1[left] = arr2[right - n]; arr2[right - n] = tmp;
                }
            } else {
                if (arr2[left - n] > arr2[right - n]) {
                    long tmp = arr2[left - n]; arr2[left - n] = arr2[right - n]; arr2[right - n] = tmp;
                }
            }
            left++; right++;
        }
        if (gap == 1) break;
        gap = (gap / 2) + (gap % 2);
    }
}

    32. Maximum Product Subarray

    Difficulty: HIGH

    Statement/Hint: Find the contiguous subarray within an array (containing at least one number) which has the largest product.

    Example: - Input: nums = [2, 3, -2, 4] - Output: 6 (subarray [2, 3])

    Approach:

    Brute Force - Check every subarray's product directly with two nested loops, tracking the running max.

    Time / Space: O(n^2) time, O(1) space.

    public int maxProduct(int[] nums) {
    int maxProd = Integer.MIN_VALUE;
    int n = nums.length;
    for (int i = 0; i < n; i++) {
        int prod = 1;
        for (int j = i; j < n; j++) {
            prod *= nums[j];
            maxProd = Math.max(prod, maxProd);
        }
    }
    return maxProd;
}

    Prefix/Suffix Product Scan - Track a running prefix product and a running suffix product simultaneously in one left-to-right pass. - Whenever either running product hits 0, reset it to 1 - a zero acts as a hard break, since no subarray crossing it can have a nonzero product, so restart the running product just past it. - The key insight: because a negative number flips the sign, the maximum product ending at some point could come from either direction (a negative in the interior can turn a small suffix product into the largest overall by pairing with another negative) - tracking both directions' running products at once captures this without explicitly enumerating sign-flip cases.

    Time / Space: O(n) time, O(1) space.

    public int maxProduct(int[] nums) {
    int maxProd = Integer.MIN_VALUE;
    int n = nums.length;
    int preProd = 1, sufProd = 1;
    for (int i = 0; i < n; i++) {
        if (preProd == 0) preProd = 1;
        if (sufProd == 0) sufProd = 1;
        preProd *= nums[i];
        sufProd *= nums[n - i - 1];
        maxProd = Math.max(maxProd, Math.max(preProd, sufProd));
    }
    return maxProd;
}

    33. Largest Element in an Array

    Difficulty: LOW

    Statement/Hint: Find the largest element in an array.

    Example: - Input: nums = [3, 7, 1, 9, 4] - Output: 9

    Approach: Linear Scan - Traverse the array once, keeping a running maximum. - Initialize the max to the smallest possible value so any array element can update it. - Compare each element against the current max and update when a larger value is found. - No sorting or extra space needed - a single pass is both necessary and sufficient.

    Time / Space: O(n) time, O(1) space.

    public int largestElement(int[] nums) {
    int mx = Integer.MIN_VALUE;
    for (int it : nums) mx = Math.max(mx, it);
    return mx;
}

    34. Second Largest Distinct Element

    Difficulty: LOW

    Statement/Hint: Find the second largest distinct element in an array without sorting it.

    Example: - Input: nums = [8, 2, 7, 7, 5] - Output: 7

    Approach: Single Pass - Track two running values: the largest seen so far and the second largest. - When the current element beats the max, demote the old max to second-largest before updating max. - When the current element is between second-largest and max (but not equal to max), update second-largest directly. - This single pass avoids the O(n log n) cost of sorting just to read off the second entry.

    Time / Space: O(n) time, O(1) space.

    public int secondLargestElement(int[] nums) {
    int mx = -1;
    int secondMx = -1;
    for (int it : nums) {
        if (it > mx) {
            secondMx = mx;
            mx = it;
        } else if (it > secondMx && it < mx) {
            secondMx = it;
        }
    }
    return secondMx;
}

    35. Check if Array is Sorted and Rotated

    Difficulty: MEDIUM

    Statement/Hint: Given an array, determine whether it is sorted in non-decreasing order and then possibly rotated some number of times.

    Example: - Input: nums = [3, 4, 5, 1, 2] - Output: true (rotated once from [1,2,3,4,5])

    Approach: Breakpoint Counting - Count "breakpoints": adjacent pairs (including the wraparound pair last-to-first) where the earlier element is greater than the next. - A sorted-then-rotated array has at most one such breakpoint (the rotation point); a plain sorted array has zero. - Explicitly check the wraparound pair (last element vs first element) - a fully sorted array still needs cnt <= 1 to pass, and skipping this check misses the boundary case. - If the breakpoint count exceeds 1, the array cannot be a rotation of a sorted array.

    Time / Space: O(n) time, O(1) space.

    public boolean check(int[] nums) {
    int n = nums.length;
    int cnt = 0;
    for (int i = 1; i < n; i++) {
        if (nums[i] < nums[i - 1]) cnt++;
    }
    if (nums[n - 1] > nums[0]) cnt++;
    return cnt <= 1;
}

    36. Find the Repeating and Missing Number

    Difficulty: HIGH

    Statement/Hint: An array of size n contains numbers from 1 to n, but one number is repeated (appears twice) and another is missing entirely. Find both.

    Example: - Input: arr = [3, 1, 2, 5, 3] - Output: repeating = 3, missing = 4

    Approach:

    Mathematical (Sum & Sum of Squares) - Let x = repeating, y = missing. Using the sum of 1..n and the sum of squares of 1..n against the array's actual sum and sum-of-squares gives two equations in x and y, solvable via (val2/val1) = x+y and val1 = x-y.

    Time / Space: O(n) time, O(1) space.

    public int[] findTwoElement(int[] arr) {
    long actualSum = 0, expectedSum = 0, actualSqrSum = 0, expectedSqrSum = 0;
    int n = arr.length;
    for (int i = 0; i < n; i++) {
        actualSum += arr[i];
        expectedSum += (i + 1);
    }
    for (int i = 0; i < n; i++) {
        actualSqrSum += (long) arr[i] * arr[i];
        expectedSqrSum += (long) (i + 1) * (i + 1);
    }
    long val1 = expectedSum - actualSum;
    long val2 = expectedSqrSum - actualSqrSum;
    long val3 = val2 / val1;
    long x = (val3 + val1) / 2;
    long y = x - val1;
    int cnt = 0;
    for (int it : arr) if (it == x) cnt++;
    if (cnt == 0) return new int[]{(int) y, (int) x};
    else return new int[]{(int) x, (int) y};
}

    XOR + Bit Bucketing - XOR all array elements with all numbers 1..n - every correctly-appearing number cancels out, leaving (missing XOR repeating). - Find any set bit in that XOR result (e.g. the rightmost set bit) - this bit must differ between missing and repeating, so it can be used to bucket all numbers (both 1..n and the array) into two groups. - XOR-ing within each bucket isolates the missing and repeating numbers into the two bucket accumulators; a final counting pass over the array determines which bucket holds the repeating vs. the missing number.

    Time / Space: O(n) time, O(1) space.

    public int[] findTwoElement(int[] arr) {
    int xorSum = 0;
    int n = arr.length;
    for (int it : arr) xorSum ^= it;
    for (int i = 1; i <= n; i++) xorSum ^= i;
    int diffBit = (xorSum & ~(xorSum - 1));
    int zeroBucket = 0, oneBucket = 0;
    for (int it : arr) {
        if ((it & diffBit) != 0) oneBucket ^= it;
        else zeroBucket ^= it;
    }
    for (int i = 1; i <= n; i++) {
        if ((i & diffBit) != 0) oneBucket ^= i;
        else zeroBucket ^= i;
    }
    int cnt = 0;
    for (int it : arr) if (it == zeroBucket) cnt++;
    if (cnt == 0) return new int[]{oneBucket, zeroBucket};
    else return new int[]{zeroBucket, oneBucket};
}

    37. Count Inversions

    Difficulty: MEDIUM

    Statement/Hint: Count the number of inversions in an array - pairs (i, j) where i < j but arr[i] > arr[j].

    Example: - Input: arr = [2, 4, 1, 3, 5] - Output: 3

    Approach: Merge Sort Augmentation - Use a modified merge sort: while merging two sorted halves, whenever an element from the right half is placed before an element from the left half, every remaining element in the left half forms an inversion with it. - Specifically, if arr[i] > arr[j] during the merge (i in the left half, j in the right half), all elements from i to the end of the left half are greater than arr[j] - add (mid - i + 1) to the inversion count in one step. - Recursively count inversions in the left half, the right half, and across the merge step, then sum all three. - This piggybacks inversion counting onto merge sort's existing O(n log n) structure instead of the brute-force O(n^2) pairwise comparison.

    Time / Space: O(n log n) time, O(n) space.

    public int merge(int[] arr, int low, int mid, int high) {
    List<Integer> temp = new ArrayList<>();
    int i = low, j = mid + 1;
    int cnt = 0;
    while (i <= mid && j <= high) {
        if (arr[i] > arr[j]) {
            cnt += (mid - i + 1);
            temp.add(arr[j]);
            j++;
        } else {
            temp.add(arr[i]);
            i++;
        }
    }
    while (i <= mid) temp.add(arr[i++]);
    while (j <= high) temp.add(arr[j++]);
    for (int k = low; k <= high; k++) arr[k] = temp.get(k - low);
    return cnt;
}

public int mergeSort(int[] arr, int low, int high) {
    int cnt = 0;
    if (low >= high) return cnt;
    int mid = (low + high) / 2;
    cnt += mergeSort(arr, low, mid);
    cnt += mergeSort(arr, mid + 1, high);
    cnt += merge(arr, low, mid, high);
    return cnt;
}

    38. Count Reverse Pairs

    Difficulty: MEDIUM

    Statement/Hint: Count the number of reverse pairs in an array - pairs (i, j) where i < j and arr[i] > 2 * arr[j].

    Example: - Input: nums = [1, 3, 2, 3, 1] - Output: 2

    Approach: Merge Sort Augmentation (separate counting pass) - This looks like Count Inversions but the counting condition (arr[i] > 2*arr[j]) differs from the sort condition (arr[i] <= arr[j]), so it cannot be counted during the same merge step as inversions. - Instead, add a separate counting pass before the merge step: for each element in the left half, advance a pointer through the right half while arr[i] > 2*arr[right], and add the number of valid right-half elements found to the count. - This counting pass runs on the sorted-but-not-yet-merged halves, using a pointer that only moves forward overall (never resets per left-half element) since both halves are already individually sorted from the recursion. - After counting, perform the standard merge step to combine the two halves into a fully sorted segment for the next level of recursion.

    Time / Space: O(n log n) time, O(n) space.

    public void merge(int[] arr, int low, int mid, int high) {
    List<Integer> temp = new ArrayList<>();
    int i = low, j = mid + 1;
    while (i <= mid && j <= high) {
        if (arr[i] > arr[j]) {
            temp.add(arr[j]);
            j++;
        } else {
            temp.add(arr[i]);
            i++;
        }
    }
    while (i <= mid) temp.add(arr[i++]);
    while (j <= high) temp.add(arr[j++]);
    for (int k = low; k <= high; k++) arr[k] = temp.get(k - low);
}

public int countPairs(int[] arr, int low, int mid, int high) {
    int right = mid + 1;
    int cnt = 0;
    for (int i = low; i <= mid; i++) {
        while (right <= high && arr[i] > 2L * arr[right]) right++;
        cnt += (right - (mid + 1));
    }
    return cnt;
}

public int mergeSort(int[] arr, int low, int high) {
    int cnt = 0;
    if (low >= high) return cnt;
    int mid = (low + high) / 2;
    cnt += mergeSort(arr, low, mid);
    cnt += mergeSort(arr, mid + 1, high);
    cnt += countPairs(arr, low, mid, high);
    merge(arr, low, mid, high);
    return cnt;
}

public int reversePairs(int[] nums) {
    return mergeSort(nums, 0, nums.length - 1);
}

    39. Left-Rotate an Array by One

    Difficulty: LOW

    Statement/Hint: Left-rotate an array by exactly one position (the first element moves to the end).

    Example: - Input: arr = [1,2,3,4,5] - Output: [2,3,4,5,1]

    Approach: Single Pass Shift - Save the first element in a temp variable, shift every other element one index to the left (arr[i] = arr[i+1] for i from 0 to n-2), then place the saved temp value at the last index. - This is the O(1)-extra-space base case that the general "rotate by K places" problem reduces to when K=1 - understanding it cleanly makes the K-places version (repeat this d times, or use the reversal trick) easier to reason about. - O(n) time, O(1) extra space.

    Time / Space: O(n) time, O(1) space.

    public void rotateByOne(int[] arr) {
    int n = arr.length;
    int temp = arr[0];
    for (int i = 0; i < n - 1; i++) {
        arr[i] = arr[i + 1];
    }
    arr[n - 1] = temp;
}

    40. Maximum Subarray Sum with Indices

    Difficulty: MEDIUM

    Statement/Hint: Given an array, find not just the maximum subarray sum but also return the actual subarray (start and end indices) that produces it.

    Example: - Input: arr = [-2,1,-3,4,-1,2,1,-5,4] - Output: subarray = [4,-1,2,1], sum = 6

    Approach: Extended Kadane's Algorithm - Run Kadane's Algorithm as usual, tracking a running sum and the best sum seen so far - but additionally track the start index of the current run and the (start, end) indices of the best run found so far. - Whenever the running sum drops below 0, reset it to 0 and mark the next index as a new candidate start. - Whenever the running sum exceeds the best sum, update the best sum AND record the current start index alongside the current index as the best end index. - O(n) time, O(1) extra space (beyond the returned indices/subarray).

    Time / Space: O(n) time, O(1) space.

    public int[] maxSubarrayIndices(int[] arr) {
    int maxSum = Integer.MIN_VALUE, sum = 0, start = 0, bestStart = 0, bestEnd = 0;
    for (int i = 0; i < arr.length; i++) {
        if (sum == 0) start = i;
        sum += arr[i];
        if (sum > maxSum) {
            maxSum = sum;
            bestStart = start;
            bestEnd = i;
        }
        if (sum < 0) sum = 0;
    }
    return new int[]{bestStart, bestEnd};
}
