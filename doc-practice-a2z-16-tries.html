    1. Implement Trie (Prefix Tree)

    Problem. Implement a Trie supporting insert(word), search(word) (exact word present), and startsWith(prefix) (any word has this prefix).

    Input: insert("apple"); search("apple"); search("app"); startsWith("app")

    Output: true; false; true

    • Each node holds an array of 26 child pointers (one per lowercase letter) and a boolean isEnd marking that a word terminates here.
    • insert: walk the word char by char, creating a child node wherever the link is missing, then set isEnd = true at the final node.
    • search vs. startsWith share the same traversal: follow links for each char, returning false if any link is missing. search additionally requires isEnd at the end; startsWith just requires reaching the end.
    • The single distinction between the two queries - checking isEnd or not - is the crux; both are O(length) and never depend on how many words are stored.
    • All operations O(L) time (L = word length), O(total chars) space.

    Time: O(L) per op | Space: O(total chars)

    26-Child Nodes with isEnd

    class Trie {
    static class Node {
        Node[] links = new Node[26];
        boolean isEnd = false;
    }
    private final Node root = new Node();

    public void insert(String word) {
        Node cur = root;
        for (char ch : word.toCharArray()) {
            int i = ch - 'a';
            if (cur.links[i] == null) cur.links[i] = new Node();
            cur = cur.links[i];
        }
        cur.isEnd = true;
    }

    public boolean search(String word) {
        Node cur = root;
        for (char ch : word.toCharArray()) {
            int i = ch - 'a';
            if (cur.links[i] == null) return false;
            cur = cur.links[i];
        }
        return cur.isEnd;
    }

    public boolean startsWith(String prefix) {
        Node cur = root;
        for (char ch : prefix.toCharArray()) {
            int i = ch - 'a';
            if (cur.links[i] == null) return false;
            cur = cur.links[i];
        }
        return true;
    }
}

    2. Implement Trie II

    Problem. Implement a Trie II supporting insert(word), countWordsEqualTo(word), countWordsStartingWith(prefix), and erase(word). Words may be inserted multiple times.

    Input: insert("apple") x2; countWordsEqualTo("apple"); countWordsStartingWith("app"); erase("apple"); countWordsEqualTo("apple")

    Output: 2; 2; 1

    • Augment each node with two counters: cntEnd (how many inserted words terminate exactly here) and cntPrefix (how many inserted words pass through this node). isEnd/isNode become counts.
    • insert: increment cntPrefix at every visited node and cntEnd at the terminal node. This makes both count queries O(L) reads at the reached node.
    • countWordsEqualTo returns the terminal node's cntEnd; countWordsStartingWith returns the reached node's cntPrefix.
    • erase mirrors insert with decrements: walk the word decrementing cntPrefix along the path and cntEnd at the end (assumes the word exists). Optionally free nodes whose cntPrefix hits 0.
    • All operations O(L) time; counters make multiplicity and prefix statistics answerable in one pass.

    Time: O(L) per op | Space: O(total chars)

    Nodes with Prefix and End Counters

    class Trie {
    static class Node {
        Node[] links = new Node[26];
        int cntEnd = 0, cntPrefix = 0;
    }
    private final Node root = new Node();

    private Node walk(String s) { // returns node at end or null
        Node cur = root;
        for (char ch : s.toCharArray()) {
            int i = ch - 'a';
            if (cur.links[i] == null) return null;
            cur = cur.links[i];
        }
        return cur;
    }

    public void insert(String word) {
        Node cur = root;
        for (char ch : word.toCharArray()) {
            int i = ch - 'a';
            if (cur.links[i] == null) cur.links[i] = new Node();
            cur = cur.links[i];
            cur.cntPrefix++;
        }
        cur.cntEnd++;
    }

    public int countWordsEqualTo(String word) {
        Node n = walk(word);
        return n == null ? 0 : n.cntEnd;
    }

    public int countWordsStartingWith(String prefix) {
        Node n = walk(prefix);
        return n == null ? 0 : n.cntPrefix;
    }

    public void erase(String word) {
        Node cur = root;
        for (char ch : word.toCharArray()) {
            cur = cur.links[ch - 'a'];
            cur.cntPrefix--;
        }
        cur.cntEnd--;
    }
}

    3. Longest Word with All Prefixes

    Problem. Given a list of words, find the longest word such that every one of its prefixes is also present in the list. Tie-break by lexicographically smallest.

    Input: words = ["a", "ap", "app", "appl", "apple", "apply"]

    Output: "apple"

    • Insert all words into a trie (marking isEnd at each word's terminal node). A word "has all prefixes present" iff every node along its path - not just the last - has isEnd set.
    • Traverse the trie with DFS, only descending into a child whose isEnd is true (that prefix is itself a complete word). Track the longest reachable word, breaking ties by lexicographic order via iterating children a..z.
    • The elegance: the "all prefixes exist" condition maps directly onto "every node on the path is an end node", so a single guarded DFS answers it.
    • No extra data structure beyond the trie is needed; the isEnd flags encode the entire constraint.

    Time: O(total chars) | Space: O(total chars)

    Trie DFS Through End-Marked Children

    class Solution {
    static class Node { Node[] links = new Node[26]; boolean isEnd = false; }
    private final Node root = new Node();
    private String best = "";

    private void insert(String w) {
        Node cur = root;
        for (char ch : w.toCharArray()) {
            int i = ch - 'a';
            if (cur.links[i] == null) cur.links[i] = new Node();
            cur = cur.links[i];
        }
        cur.isEnd = true;
    }

    private void dfs(Node node, StringBuilder path) {
        if (path.length() > best.length()) best = path.toString();
        for (int i = 0; i < 26; i++) {
            Node nxt = node.links[i];
            if (nxt != null && nxt.isEnd) { // only descend valid prefixes
                path.append((char) ('a' + i));
                dfs(nxt, path);
                path.deleteCharAt(path.length() - 1);
            }
        }
    }

    public String longestWord(String[] words) {
        for (String w : words) insert(w);
        dfs(root, new StringBuilder());
        return best;
    }
}

    4. Count Distinct Substrings

    Problem. Given a string, count the number of distinct substrings it contains (including the empty string or not, per the variant - here count non-empty distinct substrings).

    Input: s = "ababa"

    Output: 9 (a, b, ab, ba, aba, bab, abab, baba, ababa)

    • Every substring is a prefix of some suffix. So insert all suffixes of the string into a trie; each NEW node created during insertion corresponds to exactly one distinct substring.
    • Count the total number of nodes created (excluding the root). Because the trie automatically merges shared prefixes, duplicate substrings never create duplicate nodes.
    • Iterate over each starting index i, walk from i to the end creating links as needed, and increment a counter each time a new node is allocated.
    • The trie's structural deduplication is the whole trick: distinct-substring counting reduces to node counting, no hashing needed.

    Time: O(n^2) | Space: O(n^2)

    Insert All Suffixes, Count New Nodes

    class Solution {
    static class Node { Node[] links = new Node[26]; }

    public int countDistinctSubstrings(String s) {
        Node root = new Node();
        int count = 0, n = s.length();
        for (int i = 0; i < n; i++) {
            Node cur = root;
            for (int j = i; j < n; j++) {
                int idx = s.charAt(j) - 'a';
                if (cur.links[idx] == null) {
                    cur.links[idx] = new Node();
                    count++; // a new distinct substring
                }
                cur = cur.links[idx];
            }
        }
        return count;
    }
}

    5. Maximum XOR of Two Numbers

    Problem. Given an array of non-negative integers, find the maximum XOR value obtainable from any pair of elements.

    Input: nums = [3, 10, 5, 25, 2, 8]

    Output: 28 (5 XOR 25)

    • Use a BINARY trie: insert each number as a fixed-width (e.g. 32-bit) path of bits from the most significant bit down, each node having two children (bit 0 and bit 1).
    • To maximize XOR for a query number, greedily walk the trie preferring the OPPOSITE bit at each level (opposite bits XOR to 1, the maximum contribution at that position); fall back to the same bit if the opposite child is absent.
    • Insert numbers as you go and query each against the trie of previously inserted numbers (or insert all first, then query each) to find the best pair.
    • The bit-trie turns "find the partner maximizing XOR" from O(n) per element into O(32), because the greedy opposite-bit descent locks in the best choice bit by bit.

    Time: O(n * 32) | Space: O(n * 32)

    Binary Trie, Greedy Opposite-Bit

    class Solution {
    static class Node { Node[] links = new Node[2]; }
    private final Node root = new Node();

    private void insert(int num) {
        Node cur = root;
        for (int b = 31; b >= 0; b--) {
            int bit = (num >> b) & 1;
            if (cur.links[bit] == null) cur.links[bit] = new Node();
            cur = cur.links[bit];
        }
    }

    private int query(int num) { // best XOR of num with inserted
        Node cur = root;
        int res = 0;
        for (int b = 31; b >= 0; b--) {
            int bit = (num >> b) & 1;
            if (cur.links[1 - bit] != null) { // prefer opposite bit
                res |= (1 << b);
                cur = cur.links[1 - bit];
            } else cur = cur.links[bit];
        }
        return res;
    }

    public int findMaximumXOR(int[] nums) {
        int best = 0;
        for (int x : nums) insert(x);
        for (int x : nums) best = Math.max(best, query(x));
        return best;
    }
}

    6. Maximum XOR with an Element from Array

    Problem. Given nums[] and queries[i] = [xi, mi], for each query find the maximum value of (xi XOR nums[j]) over all nums[j] <= mi, or -1 if no such element exists.

    Input: nums = [0,1,2,3,4], queries = [[3,1],[1,3],[5,6]]

    Output: [3, 3, 7]

    • Build on the binary-trie max-XOR idea but add the constraint nums[j] <= mi. Solve OFFLINE: sort nums ascending and sort queries by their mi bound ascending.
    • Process queries in increasing mi order, inserting into the binary trie all nums still <= the current mi (a moving pointer over the sorted nums). Then answer the query with the standard greedy opposite-bit descent; if the trie is empty, answer -1.
    • Sorting both sides so the trie only ever contains valid (<= mi) elements is the key: it converts a per-query filter into a monotonic incremental insertion.
    • Remember to map answers back to the queries' original indices after sorting.

    Time: O((n + q) * 32) | Space: O(n * 32)

    Sort Queries Offline + Binary Trie

    class Solution {
    static class Node { Node[] links = new Node[2]; }
    private final Node root = new Node();

    private void insert(int num) {
        Node cur = root;
        for (int b = 31; b >= 0; b--) {
            int bit = (num >> b) & 1;
            if (cur.links[bit] == null) cur.links[bit] = new Node();
            cur = cur.links[bit];
        }
    }

    private int query(int num) {
        Node cur = root;
        int res = 0;
        for (int b = 31; b >= 0; b--) {
            int bit = (num >> b) & 1;
            if (cur.links[1 - bit] != null) { res |= (1 << b); cur = cur.links[1 - bit]; }
            else cur = cur.links[bit];
        }
        return res;
    }

    public int[] maximizeXor(int[] nums, int[][] queries) {
        Arrays.sort(nums);
        int q = queries.length;
        int[][] qs = new int[q][3]; // {mi, xi, originalIndex}
        for (int i = 0; i < q; i++) qs[i] = new int[]{queries[i][1], queries[i][0], i};
        Arrays.sort(qs, (a, b) -> a[0] - b[0]);
        int[] ans = new int[q];
        int ptr = 0, n = nums.length;
        for (int[] cur : qs) {
            int mi = cur[0], xi = cur[1], idx = cur[2];
            while (ptr < n && nums[ptr] <= mi) insert(nums[ptr++]);
            ans[idx] = (ptr == 0) ? -1 : query(xi);
        }
        return ans;
    }
}

    7. Replace Words

    Problem. Given a dictionary of root words and a sentence, replace every word in the sentence with the SHORTEST root in the dictionary that is a prefix of it. If no root applies, keep the word.

    Input: dictionary = ["cat","bat","rat"], sentence = "the cattle was rattled by the battery"

    Output: "the cat was rat by the bat"

    • Insert all dictionary roots into a trie, marking isEnd at each root's terminal node.
    • For each sentence word, walk the trie character by character; the moment you reach a node with isEnd = true, you have found the shortest matching root - stop and emit that prefix. If a link is missing before any root ends, emit the original word.
    • Stopping at the FIRST end node encountered guarantees the shortest root (shorter prefixes are reached earlier during the descent), which is exactly what the problem asks for.
    • This is a straightforward application of the base trie: the isEnd flag plus early termination answers "shortest dictionary prefix" per word in O(word length).

    Time: O(total chars) | Space: O(dictionary chars)

    Trie of Roots + First-End Match

    class Solution {
    static class Node { Node[] links = new Node[26]; boolean isEnd = false; }
    private final Node root = new Node();

    private void insert(String w) {
        Node cur = root;
        for (char ch : w.toCharArray()) {
            int i = ch - 'a';
            if (cur.links[i] == null) cur.links[i] = new Node();
            cur = cur.links[i];
        }
        cur.isEnd = true;
    }

    private String shortestRoot(String w) {
        Node cur = root;
        StringBuilder prefix = new StringBuilder();
        for (char ch : w.toCharArray()) {
            int i = ch - 'a';
            if (cur.links[i] == null) return w; // no root is a prefix
            prefix.append(ch);
            cur = cur.links[i];
            if (cur.isEnd) return prefix.toString(); // first (shortest) root
        }
        return w;
    }

    public String replaceWords(List<String> dictionary, String sentence) {
        for (String w : dictionary) insert(w);
        StringBuilder res = new StringBuilder();
        String[] words = sentence.split(" ");
        for (int i = 0; i < words.length; i++) {
            if (i > 0) res.append(" ");
            res.append(shortestRoot(words[i]));
        }
        return res.toString();
    }
}
